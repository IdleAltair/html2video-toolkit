# 参考音源来源与许可

本目录的 wav 是从公开视频中提取、去 BGM 后得到的人声参考，用于 BreezeTTS 音色克隆。

- 来源：B 站视频《谁最会说人话？我抓了6个AI挑战地狱级测试！【牢大百科10】》的人声片段
- 处理：`audio-separator` + BS-RoFormer 分离出人声（原始时长片段见文件名 `vocal_tXX_起-止`）
- 说明：该人声本身是「牢大」使用开源的**早见沙织**声音二次生成（TTS）的产物
- 许可：MIT，可自由用于本项目相关的配音实验与复现

`ref_text.txt` 是对应参考片段的文本。请仅用于技术复现，不要用于冒充或误导性用途。

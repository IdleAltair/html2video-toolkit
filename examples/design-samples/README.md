# sample · 设计语言模板

把 `../docs/design-language-*.md` 的 7 套方案各落成一个**可直接录屏的单文件 HTML**。
7 套渲染同一份示例内容（文件内的 `SHARED DECK v1` 块），差异只在风格，便于横向选型。

## 一览

|---|---|---|---|---|---|
| 00 | 远岸 | `far-horizon.html` | odometer 数字 + 扫表 | whip / checker / shutter | 全黑（落旗断电） |
| 01 | 蓝图 | `blueprint.html` | 800px/s 恒速绘制 + 尺寸标注丈量 | 换图下移 / 圈注深入 | 蓝底 + 网格，无文字 |

## 选型台

`index.html`：7 格并排渲染同一页内容，切页码即横向比风格，附 catalog 速查表。
默认走 `?noanim` 省资源，勾「带动效」可看真实进场；点某格的「打开」看该套全尺寸。

## 用法（7 套一致）

    far-horizon.html            双击打开即看
    ?noanim       降级版：转场 1 帧直切、进场直呈终态、图表静态（走时与 REC 等信息载体保留）
    ?clean=1      录屏：隐藏鼠标与左下角键位提示条
    ?slide=3      直接定位到第 4 页

键位：`→` / `Space` / `PageDown` 下页，`←` / `PageUp` 上页，`Home` / `End`，`F` 纯净屏，`A` 切 `?noanim`。
鼠标：滚轮翻页（累计过阈值才翻，触控板惯性不连跳），点两侧 28% 翻页、中间 44% 安全区；转场期间加锁不叠加。

终场黑屏是**定格不是死屏**：滚出干净帧后，任何翻页输入都会解除定格、还原被收走的元素，
再翻回末页重播整套退场。录完回看不必刷新。

画布 2560×1440，窗口不足时整体等比缩放（不改版式）。录屏开 2560×1440 窗口即为 scale=1。

## 换内容

只改 `/* ===== SHARED DECK v1 ... ===== */` 到 `SHARED DECK 结束` 之间的块，渲染逻辑不动。
页型 6 种：`cover` / `metric` / `ranking` / `divider` / `transcript` / `final`，`type` 决定骨架，其余字段喂文本与数值。

**7 套的这块必须逐字一致**，否则横向对比失真。校验：

    for f in *.html; do awk '/SHARED DECK v1/,/SHARED DECK 结束/' $f | md5sum; done

方案身份（`DECK.meta.style` / `.doc`）**不在**共享块里，各套在块尾自行声明——
共享内容里混进"00 FAR HORIZON"这类字段会让别的方案错标自己。块内数字均为占位示例，不是实测成绩。

## 已实测

七套逐套跑过同一把尺子（无头 Chrome + 项目自带 puppeteer-core，2560×1440，逐页取动效终态）：
语法与骨架钩子、六种页型字号 ≥24px、无元素出画、终场定格可解除、鼠标三条通路、
`?noanim` 文本量不低于动画版、全程无 JS 报错，结果 **7 套全部 36 PASS / 0 FAIL**
（各套剩下的 1 条 WARN 都是文档特批的循环动画或退场时长，逐条出处见各套文件头注释）。
另确认七套都能收束到**无残留文字的干净帧**。校验器本身做过反向对照：
撤掉定格解除逻辑、把正文压到 18px、故意留一处出画，都能被抓成 FAIL，不是空转的测试。

脚本目前放在我的工作区 `$WORKSPACE\.fh-check\`（`verify.cjs` / `frames.cjs`），
不在本项目内——要的话我搬进 `sample/tools/` 并接上 `pipeline/check.mjs` 那类入口。

## 三条待你定

1. **退场时长**：catalog 通则写「退场总时长 1–2s」，但 05 合成波细则明写两个 1s 段（落日沉降 + 天空压暗），
   实测约 3.1s 无法压进通则。是细则优先，还是把 05 的退场改短，需要你裁。
2. **02 的干净帧**：规范要「纸白 + 页码」，它用一层纸白罩收束，把页码一起盖住了。差一处页码，改法是把罩层降到页码之下。
3. **§9 第 10 条全部未证**：七套都把「H.264 压缩后小字仍清晰」标成需人工判断。
   24–26px 的注释、0.75–1px 的细线只有真录一条压一遍才算数，我可以挑两套录一版给你看。

# Qwen3.8-27B · 不同量化效果直观对比（v3 展示页 · P5R 风格）

单文件 HTML 演示页 v3：3 个测试项目 × 3 个量化 = 9 段本地模型生成的动态 HTML 实机录像
（总时长 152s），16 页。P5R 构成主义风格：倾斜色块、斜切擦除转场、半调网点、胶片颗粒、
对角贯穿斜线、轨道圆点、脉冲圆、旋转弧线、竖排文字条、巨型描边数字。
双击 index.html 即可打开（file:// 直接可用，无外部依赖），内置 28.8s 循环 P5R 风轻快空灵配乐（立体声）
（assets/music-loop.wav，100 BPM 近直摆，铃铛主旋律 + 空气 pad + 流动琶音 + 沙球 + upright walking bass，4.5min 自动导览循环约 9 遍）。

与 v1（$DESKTOP\screenshot\llm-html2video\）的差异：
- 转场：三层斜切色带（红边锋 → 墨色半调主体 → 项目色尾随带），L/R 横段 skewX(-14°)、U 竖段 skewY(-14°)，
  前进/后退方向镜像；三个章节边界（进入 06/10/14，含反向跨章）改用 6 块马赛克幕
  （随机不规则色块错落进出，含一大圆块）；约 0.8s（斜切）/ 约 1s（马赛克），无残影
- 风格：元素普遍带小角度倾斜（标题 -1.6°、卡片 -0.6°、标签 -6° 等）+ 错位投影 + 红色偏移阴影
- 每页自适应背景（按信息密度配置）：
  · 封面/滚筒/结尾（密度低）= 丰富：3 层对角贯穿斜线（加粗加深）+ 不规则大斜块 +
    轨道圆（环上圆点游动）+ 脉冲圆（扩散消散）+ 旋转弧线 + 速度线 + 点阵
  · 录像页（视频是主角）= 边距丰富、中央干净：巨型描边数字、轨道环、弧线、斜线、竖排条
  · 设定/总结（密度高）= 克制：细斜线 + 小弧线 + 稀疏点阵，只起衬托
- 提示词改为代码块结构：深色面板 + 行号 + 等宽字体 + 红色滚动条，标题栏带 SCROLL 提示；
  字号固定 1.62vh 不再缩小，项目三长提示词手动滚动展示（录制时下拉即可）
- 全局胶片颗粒（SVG 噪声，6% multiply）
- 录像页信息行加闪烁 REC 圆点，按视频标注实际分辨率
- 结束页鸣谢放大：主标题条带化 + 大字号行 + 风格监督:我（"我"两行红色高亮）
- 配乐重写（第七版，轻快空灵，立体声）：100 BPM 近直摆（C 大调，参考 Inkling 视频 BGM 的明亮空气感）：
  铃铛主音（微非谐泛音 2.76f/5.4f + 点 8 分延迟 shimmer）+ 空气 pad（失谐正弦、慢起振、宽声像）
  + 交替 L/R 流动琶音 + 沙球 8 分驱动 + 轻滚 kick + 刷鼓（含鬼音）+ hat（第 4/8 小节 16 分加花）
  + upright walking bass + Rhodes 和声 comping + 轻 whoosh 呼应网页擦除转场；
  轻快、明亮、空灵，12 小节无缝循环（28.8s），混响加重（wet 0.28）、末小节 pad 提前收 + 缝合淡变保证循环无缝；
  生成器 pipeline/music_p5r_v7.mjs（纯 Node、无依赖，BPM/配器/音量/声像可调重渲染）；
  上一版 v6（88 BPM 摇摆爵士、弱音小号，仿 Beneath the Mask 声色，去沙哑版）存档

  第一次播放结束淡出退出全屏、原位继续循环（视频移除 loop 属性，靠 ended 事件感知“首播完”）；重新进入该页重新走一遍

## 操作

    → / 空格 / PageDown   下一页
    ← / PageUp            上一页
    1 - 9                 直接跳到第 1-9 段录像
    0                     跳到其他作品（滚筒）
    Home / End            封面 / 结尾
    F                     纯净屏（隐藏底部栏 + 隐藏鼠标，等同 ?clean=1 的开关；不走浏览器全屏 → 无 Esc 提示条）
    P                     当前录像"全屏"播放（铺满窗口，不走浏览器全屏 → 无 Esc 提示条；再按 P / Esc / 点击 退出）
                          进入全屏有淡入+轻微放大转场；视频循环播放，手动退出（P / Esc / 点击）时淡出回录像页并续播
    M                     音乐 开/关
    A                     自动导览 开/关（每页空白处的虚线圆顺时针旋转，实线弧自正下方红点闭合一圈 = 本页倒计时，
                          闭合即自动翻到下一页；驻留：轻页 4s / 密页 9s / 录像页 4s+片长 / 总结 10s / 滚筒转一圈 30s+6s；手动翻页退出）
    ?auto=1               加载即开启自动导览（录屏用，可叠加 ?clean=1 隐藏 HUD）
    进入录像页            切到对应界面后 2s 视频自动起播并循环播放；离开该页即暂停并取消未触发的自动播放
    点击视频框            同 P（播完自动退出）
    滚轮（提示词页）      提示词默认自动滚动（进页先停 1 秒，再 5 行/秒），滚轮一碰即停、接管滚动
    → / 点击灯绳（末页）  拉下灯绳落幕：黑红渐变幕布垂落盖住画面 → 纯黑（Esc / ← / 点击黑屏 复位可重录）
    点击其他区域          下一页
    ?clean=1              URL 加参数隐藏底部 HUD（录屏用）

# Qwen3.8-27B · 不同量化效果直观对比（展示页）

单文件 HTML 演示页：3 个测试项目 × 3 个量化 = 9 段本地模型生成的动态 HTML 实机录像，
构成主义 × 极简风格，16 页，色块擦除转场（无残影），内置 43.6s 循环构成主义配乐（assets/music-loop.wav）。
双击 index.html 即可打开（file:// 直接可用，无外部依赖）。

## 目录结构

    presentation/
      index.html      展示页本体（自包含）
      assets/         9 张海报图（视频缺位时的占位 + 汇总页缩略图）
      videos/         保留目录，当前默认不使用（视频在 $OUTPUT_DIR，见下）
      README.md

## 视频位置与命名

视频在 **$OUTPUT_DIR\**，页面用相对路径 ../../../../shotcut/ 引用。
若移动了展示页或视频目录，改 index.html 顶部脚本里的常量：

    var VID_ROOT = "../../../../shotcut/";   // 改成任意相对/绝对路径

## 修改内容

- 量化/项目/数据：改 index.html 顶部脚本的 QUANTS / PROJECTS / ENV 常量
  （in/out/kv/comp/dur/cut/src 都在 data 里；合计 tin/tout/tcomp 在 QUANTS 里）。
- 完整 prompt：改 <script type="text/plain" id="prompt-N"> 三个文本块，页面原样显示。
- 主题色：CSS 顶部 --p1 / --p2 / --p3（脚本里 PHUE 数组同步）。
- 海报图：assets/shot-<项目id>-<量化>.png（1280×720），换图同名覆盖即可。

## 设计说明

底色米白 #f1ebdd、墨黑 #171310、构成红 #d93a12；硬阴影（无模糊）、粗描边、
斜切色块、同心圆/折线 motif（波浪/涡旋/闪电对应三个项目）、半调网点、
角部注册十字、胶片齿孔视频框、时间码行、底部录像进度轨（9 格项目色 + 1 格红）。

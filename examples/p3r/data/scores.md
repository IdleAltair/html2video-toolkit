# 本地 27B 成绩对比（三集）

模型：Qwen3.8-27B-Uncensored（llama.cpp，Q5_K_XL，双卡 tensor 切分，MTP 开）
工具：DSH 0.2.0-rc.2 Web GUI，预设 `ptc-local-concise`，思考档 Max
时间一律精确到分钟。

## 口径警告（视频里必须显著标注）

1. **不同集之间分数不可比。** 圈地是"greedy=0、该模式最强=100"的归一化分；炸弹人和夺旗是"基准=0、400×log10、不封顶"的 Bradley–Terry 实力值。
2. **本地成绩与正式赛成绩不在同一张表里。** 本地走的是各集 `challenge.py` 的精简挑战赛（圈地 376 局、炸弹人 330 局），正式赛是圈地 30000 局、炸弹人 8930 局、夺旗 32010 局。局数少则排名起伏大——同一个 Opus 5.5 在圈地正式赛是 79.4 分，在本地这张挑战赛表里是 51.5 分。**只有同一张表内的数字可以互相比较。**
3. **时限不同。** 正式赛是 60 分钟建议 / 90 分钟硬停；本地放宽到 90 / 120。
4. **harness 不同。** 正式赛各家用自家工具（Claude Code / Codex / ZCode / Kimi Code / dsh），本地统一用 DSH。夺旗那集的附加实验显示，同一模型只换工具，实力值能差 120 分以上。
5. **炸弹人这一场提示词有偏差**（见文末），该场成绩只能算"偏差条件下的参考值"。

## 加时赛：每场追加 40 分钟自迭代窗口

规则与正赛不同：**题目不重做，只给两样东西**——它这份 bot 的真实成绩，和一句方法论（"先让 bot 赢过基准，之后每一轮都让新版和旧版同场对打，净胜为正才留下这个改动，否则回滚"）。方向完全由模型自己定，不设"只改一处""限时多少局"这类硬约束。圈地与炸弹人两场主办方额外提供了对打脚手架（`tools/selfplay.sh`，见 `report/overtime-interruptions.md` 同目录），夺旗一场没有（它上一轮已经自己摸清 `arena.py batch` 的用法）。

### 炸弹人加时赛挖出的东西值得单独一段

v4 的根因是一个字节数写错的 `memcpy`：`bot.cpp` 里 `memcpy(R.flame, FL, 625)`，而 `flame` 声明是 `int16_t flame[625]`（1250 字节）——**只复制了一半，棋盘第 312 格之后的火焰全部丢失**。同一行的 `R.grid` 是 `uint8_t[625]`，625 字节正好，所以没暴露问题；`fown` 是 `uint16_t[625]`，同样被截断。

按引擎的 `size = 2*ceil(sqrt(14n))+1` 算各人数档受影响的格数：2/3/4 人局是 169/225/289 格，**一格都不受影响**；5 人局 49 格、8 人局 217 格、**10 人局 313 格——正好一半棋盘看不见火焰**。所以"1v1 赢基准、多人档输给基准"这个贯穿三场的模式，在炸弹人这一场不是策略问题，是这个 bug 只在棋盘 ≥313 格时才发作。它的致命格过滤和根节点评估在 10 人局的后半盘上等于瞎了。

修复后的实测（它自己做的 5 种子对照）：10 人局场均 2.0 → 2.2 → **6.5**，第 6 回合自爆 3/5 → **0/5**，故障 5 局 → **0 局**，首回合耗时 1561–1800ms → 50–70ms。官方评测里 10 人档合计分 1.584 → **3.515**（同档基准 2.024），**第一次超过基准**。

名次没动（还是第 8）：同一张表里其他选手的分数也在漂（Kimi K3 涨到 258.86、GLM 166.61），所以 +88 分只够从"豆包之上"爬到"GLM 之下"的第 8 位。**分数是真涨了，名次是噪声。**

夺旗分档：2 人档 −258 → **+62**、3 人档 −29 → −61、5 人档 −149 → −29、8 人档 −89 → −34。

**噪声口径必须一起看**：这是同一套 180 局配置下的两次独立评测，表里其他选手也在动（GPT-6 Astra 181→220、Fable 178→144、豆包 −187→−199），漂移量级约 ±40。+153 明显大于这个量级，且方向与它自己 `ITERATION_LOG.md` 的记录一致（3 人档场均得分 4.7 → 11.7）。

它在加时赛里做对的三件事，正赛都没做过：

1. **主动补测多人档**。正赛 106 分钟里它的对局测试 100% 是 2 队局，第一次 3/5/8 队测试出现在加时赛第 3.7 步（21:14），比正赛强制交卷还晚 31 分钟。
2. **找到真正的病根**："中心枪 33 + 围剿 32 永远高于抢旗任务 ~0.1，三个单位钉死在本基地 350 回合 0 分"——用一个开关门槛（SW gate）一刀解决，而不是继续在 1v1 上调参。
3. **自己量化噪声**。它做了"同一份代码换座位"的对照，测出 ±1.5–2 分是座位噪声，并据此判定"×3 权重与不 ×3 的差异落在噪声内"，没有把随机性当成果。

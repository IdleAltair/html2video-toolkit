## 0. 主题立意

**平涂 × 骨线 × 留白。**

把内容画成一幅现代浮世绘。和纸底、木版套色、骨线勾勒:平涂色块、粗骨线、留白即余韵。动效哲学是"版画动起来"——波纹扩散、云气横流,全部限定在平涂色块的物理里,绝不立体、绝不透视。

公式:

> **每一页是一版:骨线先印,色块后套,文字最后落。**

叙事隐喻:观众在看一幅徐徐展开的绘卷,每翻一页是换一版;结尾收卷钤印,画成。情绪定位:全部方案里唯一"暖"的一套,适合讲故事。

---

## 1. 设计原则(五条,按优先级)

1. **平涂无渐变。** 色块平涂,3–5px 骨线收边;木版套印的物理不容立体与透视。
2. **套色纪律。** 每屏色相 ≤ 3(靛蓝、朱红、金泥三选二 + 墨)。
3. **朱红是落款。** 每屏 ≤ 2 处,语义固定"落款/结论"。
4. **留白即余韵。** 空出来的和纸就是构图;内容区不得铺满。
5. **录制优先。** 字号与对比度以 2560×1440 录屏经 H.264 压缩后仍清晰为准(§9)。

## 2. 色彩系统

### 2.1 色板(token)

```css
:root{
  --washi:  #F2EAD8;  /* 和纸:暖米,带极轻纤维纹理(噪声 3%) */
  --indigo: #1B3A5C;  /* 靛蓝:主骨线与大色块 */
  --shu:    #C73E2C;  /* 朱红:点题色,落款/关键值 */
  --sumi:   #2B2B28;  /* 墨:正文 */
  --gold:   #B98A2F;  /* 金泥:次级强调,仅线与小面 */
  --mist:   #8FA3B0;  /* 霞灰:次要层 */
}
```

### 2.2 配色约束

| 规则 | 约束 |
|---|---|
| 套色纪律 | 每屏色相 ≤ 3:靛蓝、朱红、金泥三选二 + 墨 |
| 平涂 | 无渐变;色块必须由 3–5px 靛蓝或墨骨线收边(木版套印感) |
| 朱红用量 | 每屏 ≤ 2 处,语义固定为"落款/结论" |
| 金泥 | 仅线与小面,不作大色块 |
| 禁止 | 透视、阴影、立体、照片写实、西洋几何装饰(直格纹、checker) |

### 2.3 对比度硬指标(录屏压缩后)

- 正文/底:≥ 10:1(`--sumi` on `--washi` ≈ 12:1,达标)
- 靛蓝/底:≥ 8:1(≈ 9.7:1,骨线与大字达标)
- 朱红/底:≥ 4:1(≈ 4.2:1;朱红仅落款与结论值,不作小字号正文)
- 霞灰/底:仅作色带(平涂宽带斜托),不承载文字;其上一律墨色(墨 on 霞灰 ≈ 5.5:1)

## 3. 字体与排版

### 3.1 字族

| 角色 | 字体 | 说明 |
|---|---|---|
| 标题 | Noto Serif SC 900 | 允许竖排(签名排版);横排时字距 +0.05em |
| 正文 | Noto Serif SC 400 | 行高 1.9,全方案最松 |
| 数字 | tabular 衬线 | Old-style figures 禁止,录屏需等高 |

### 3.2 字号阶梯(2560×1440 基准)

| 层级 | px | 用途 |
|---|---|---|
| 竖排大标题 | 96–128 | 右缘签名位 |
| 横排标题 | 64–84 | 字距 +0.05em |
| Hero 数值 | 96–144 | 结论值,朱红只此一处 |
| 正文 | 30–34 | 行高 1.9;硬下限 28px |
| 注释/竖排小字 | 24–26 | 数值竖排标注;低于 24px 删除 |

### 3.3 排版约束

- **落款**:每页右下一枚 48px 正方形朱红"印",内刻页码篆意数字(白文),全片统一位置——签名元素。
- 竖排标题居右缘,自上而下、自右而左;横排正文一律左对齐。
- 标题必须是**意象句**("第三夜,潮水改道"),名词短语只配做卷目。
- 数值以竖排小字标注在图形旁,朱红只标结论值。
- 单行不超过 30 字;绘卷不挤字。

## 4. 版式与栅格

### 4.1 画布

2560×1440,安全边距四边各 96px;内容区 2368×1248,无硬栅格——绘卷以留白与色带分区。

### 4.2 绘卷结构

```
│ 右缘:竖排大标题(签名位,96–128px)                       │
│ 主区:骨线波 / 山形序列 / 霞带托内容,留白 ≥ 40%          │
│ 章节界:云气纹带横向贯穿                                  │
│ 右下:48px 朱红落款印(页码白文)——全片固定位             │
```

### 4.3 图形母题(白名单)

1. **骨线波**:平涂靛蓝 + 白骨线的层叠波,3–5 层,表"历程/量级"。
2. **云气纹**:转角云纹带,横向贯穿,表章节分隔。
3. **円相**:墨或金泥一笔圆(允许书法飞白),表"阶段完成"。
4. **霞带**:`--mist` 平涂宽带斜托内容,全方案唯一允许的斜元素。

禁止:透视、阴影、立体、照片写实、西洋几何装饰(直格纹、checker)。

## 5. 数据可视化规范

| 场景 | 规定形式 | 约束 |
|---|---|---|
| 对比 | 波高(骨线波层) | 层级即量级,数值竖排标注于旁 |
| 排行 | 山形序列 | 等高平涂山脊一字排开,本机座染朱红 |
| 时间 | 云纹带刻度 | 刻度用墨点小字 |
| 阶段完成 | 円相 | 墨或金泥一笔圆,每页 ≤ 1 枚 |
| 结论值 | 朱红竖排小字 | 每屏 ≤ 2 处朱红(含落款印) |

- **禁止坐标轴与网格**——浮世绘没有直角坐标系,量级靠形的大小与落款数字。
- 图表转译为版画语汇;任何"画成图表"的冲动都打回重画。

## 6. 页面类型与应用

| 页型 | 骨架 | 要点 |
|---|---|---|
| 封面 | 竖排卷题 + 円相一枚 | 套印进场;朱红仅落款印 |
| 叙事页 | 霞带托正文 + 竖排小标题 | 行高 1.9;每版一事 |
| 数据页 | 骨线波 / 山形序列 + 竖排数值 | 结论值朱红;无坐标轴 |
| 章节页 | 云气纹带 + 卷目 | 云过 600ms 承上启下 |
| 结束页 | "完"字小品(§7.5) | 全片最大一枚朱红印 |

## 7. 动效语言

### 7.1 节奏基调

- 缓动:套印与横卷 `cubic-bezier(0.3,0,0.2,1)`;波纹匀速扩散。
- 时长预算:微交互 ≤ 200ms;元素进场 300–500ms;翻页 500ms;章节过渡 600ms。**任何单段动画 ≤ 800ms。**
- 版间停顿:三版之间各停 150ms,像等墨干。

### 7.2 签名动效:套印

每页元素按"版次"进场:
1. 先骨线(300ms 描画);
2. 再色块(从骨线框内擦入 400ms);
3. 最后文字淡落(200ms);
4. 三版之间停顿 150ms,像等墨干。

### 7.3 翻页转场(白名单)

1. **横卷(默认)**:整页横向卷动(右入左出),500ms,`cubic-bezier(0.3,0,0.2,1)`,页缘露出 8px 和纸卷边。
2. **云过(章节切换)**:云气纹带横向流过全屏 600ms,承上启下。

禁止:透视推近、3D 翻转、弹跳——绘卷只有平面运动。

### 7.4 图表动效

- **波式强调**:关键值出现时,身后展开 2 圈骨线波纹(平涂圆环扩散 + 淡出,800ms 封顶)。
- 骨线波与山形按套印顺序进场(§7.2),不做高度生长——版画画不出"生长"。

### 7.5 结束页与退场 · 收卷落款

- 结束页 = 一幅"完"字小品:中央円相一枚,内书"完"(墨),右下落款处钤全片最大一枚朱红印(96px,白文)。
- 退场(按序执行):
  1. 印章从 1.15 倍缩至 1.0 落定,带 80ms 顿感,如钤印;
  2. 云气纹带横过全屏(600ms);
  3. 整页从右向左**收卷**成画轴(500ms,横卷的逆运算);
  4. 画轴缩小居中;
  5. 整体明度缓沉至墨黑(1.2s);
  6. 留印位一点朱红,800ms 后熄;
  7. 全黑停 ≥ 1s,供录屏切尾。
- 干净帧:全黑,或和纸底 + 朱红印一枚(二选一,定稿时锁定)。

### 7.6 背景层动效

循环允许:骨线波 10s 周期 ±4px 横移(浮世绘的海永远在动);其余静止。

### 7.7 降级(?noanim)

套印直呈完成态(骨线、色块、文字同帧);横卷与云过 1 帧直切;波纹以静态双环呈现。落款印、页码照常——降级版信息必须完整,服务录屏截图与印刷导出。

## 8. 文案语调

- 绘卷体:短句、意象、克制;允许"第三夜""潮水改道"式叙事标注。
- 数字先行不适用于本方案:先给画面,数值以竖排小字随后——但每数必标。
- 禁止感叹号;情绪交给朱红与留白。

## 9. 质量清单

1. 每屏色相 ≤ 3(靛蓝/朱红/金泥三选二 + 墨)?
2. 色块全部平涂 + 3–5px 骨线收边?无渐变、无透视、无阴影?
3. 朱红 ≤ 2 处且仅"落款/结论"语义?
4. 每页右下 48px 落款印在位,页码白文?
5. 无坐标轴与网格?数值竖排标注在图形旁?
6. 斜元素只有霞带?
7. 最小字号 ≥ 24px?正文 ≥ 28px、行高 1.9?
8. 单段动画 ≤ 800ms?循环仅骨线波横移?
9. ?noanim 版信息完整?
10. 2560×1440 截图经 H.264 压缩后,竖排小字仍清晰可读?

## 10. 与既有方案的边界

| | 瑞士网格(02) | 白盒画廊(06) | 浮世绘现代(本方案) |
|---|---|---|---|
| 底 | 纸白 | 展墙白 | 和纸(暖米,3% 纤维) |
| 高光 | 瑞士红 | 藏青 | 朱红(落款/结论) |
| 母题 | 毛发线/编号圆/脚注带 | 展线/展台/空墙 | 骨线波/云气纹/円相/霞带 |
| 坐标系 | 12 列数学栅格 | 留白与展墙 | 无直角坐标系 |
| 动效气质 | 落版急停 | 导览推移,最慢 | 版画动起来 |
| 收尾 | 版权页停格 | 闭馆空墙 | 收卷落款 |

浮世绘是全部方案里唯一"暖"的一套:白盒与瑞士的留白是理性,浮世绘的留白是余韵。任何一页若与姊妹方案签名元素撞车(编号圆、展线),回到 §4.3 母题白名单内解决。

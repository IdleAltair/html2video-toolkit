# 设计语言 · 磷光终端 PHOSPHOR

> 版本 v1.0 · 2026-10-14
> 适用:llm-html2video 动态网页演示(2560×1440 录屏,键盘翻页,单文件 HTML)
> 参照系:1980 年代琥珀单色监视器——显像管、扫描线、磷光余韵
> 姊妹方案见目录:[design-language-catalog.md](design-language-catalog.md)(本文为其方案 03 的完整版)

---

## 0. 主题立意

**一切都是字符,一切都在示波。**

炭黑底、琥珀磷光字、扫描线、辉光余韵。它不是"复古皮肤",而是一套完整的限制:只能用终端字符表达一切——这限制本身就是风格。

公式:

> **机器永远在轻微地活:游标在闪,走时在走,磷光在衰减。**

叙事隐喻:观众在看一盘 1985 年的机房录像带——一次任务被原样回放成终端会话。数据不是图表,是打印输出;强调不是颜色,是亮一档的磷光。与远岸的区别:远岸是 2020s 的冷静纪念碑,磷光是 1985 的嗡鸣机柜。远岸静止,磷光**永远在轻微地活**(闪烁、游标、扫描)。

---

## 1. 设计原则(五条,按优先级)

1. **单色纪律。** 除 `--alert` 外无第二色相;明暗只用磷光三阶(hi / 主 / lo)。
2. **字符格即栅格。** 一切对齐字符格(ch 单位);元素间距以整行计,禁止像素级随意摆放。
3. **活的是机器,不是内容。** 游标、走时、扫描是机器运转的证据,允许常动;内容元素不做无关运动。
4. **辉光是物理,不是装饰。** `0 0 8px currentColor` 级微辉光来自显像管,是全方案唯一允许的发光。
5. **录制优先。** 暗底亮字以 H.264 压缩后仍清晰为准;扫描线 8% 不得再加深(§9)。

## 2. 色彩系统

### 2.1 色板(token)

```css
:root{
  --tube:    #0A0806;  /* 显像管黑:极轻暖相 */
  --phos:    #FFB000;  /* 琥珀磷光:主色,一切文字与图形 */
  --phos-hi: #FFD25F;  /* 高亮磷光:当前行、结论值 */
  --phos-lo: #7A5200;  /* 衰减低磷:注释、坐标轴、已读内容 */
  --alert:   #FF3C1E;  /* 告警红橙:仅错误/负值,每屏 ≤ 2 处 */
}
```

### 2.2 配色约束

| 规则 | 约束 |
|---|---|
| 单色纪律 | 除 `--alert` 外无第二色相;层级用磷光三阶表达 |
| `--alert` 用量 | 每屏 ≤ 2 处,仅错误/负值 |
| 辉光 | 所有元素带 `0 0 8px currentColor` 级微辉光;禁止更强的光晕 |
| 扫描线 | 叠加层 1px 黑线每 3px 一条、透明度 8%,固定不平移 |
| 暗角 | 四角 8% 黑径向(显像管曲率暗示),不得更深 |

### 2.3 对比度硬指标(录屏压缩后)

- 正文/底:≥ 9:1(`--phos` on `--tube` ≈ 10:1,达标)
- 高亮/底:≥ 12:1(`--phos-hi` ≈ 13:1,达标)
- 低磷/底:≥ 2.5:1(`--phos-lo` ≈ 2.7:1,单色显示器的物理下限;仅注释与已读内容,正文禁用)
- 告警/底:≥ 4.5:1(≈ 5.3:1,达标)

## 3. 字体与排版

### 3.1 字族

| 角色 | 字体 | 说明 |
|---|---|---|
| 一切西文/数字 | IBM Plex Mono(备选 VT323) | 全等宽,tabular |
| 中文 | 等宽黑体 | 对齐字符格,2ch 一字 |

唯一字体政策:全方案只用等宽;无衬线黑体标题禁止。

### 3.2 字号阶梯(2560×1440 基准)

| 层级 | px | 用途 |
|---|---|---|
| Hero 数字 | 96–144 | 结论值,打出后亮一档 |
| 标题行 | 56–72 | `═` 双线标题栏 |
| 正文 | 28–32 | 行高 1.5,硬下限 28px |
| 注释/状态栏 | 24,`--phos-lo` | 低于 24px 删除,不缩小 |

### 3.3 排版约束

- 一切对齐**字符格**(ch 单位),栅格即字符格:行高 1.5,元素间距以整行计。
- 每页顶部一行状态栏:`REC ● 00:04:12 ▮ TTY1 80×25` 风格,等宽,`--phos-lo`。
- 游标 `▮` 常驻于当前行尾,530ms 闪烁——签名元素。
- 左边距 2ch;面板用线框字符(§4.3),不用灰底。
- 负值与错误:`--alert` 色并以 `!` 前缀。

## 4. 版式与栅格

### 4.1 画布

2560×1440,安全边距四边各 64px(约 4ch × 2 行);内容按 80–120 列字符格排布。

### 4.2 终端结构

```
┌ 状态栏:REC ● 00:04:12 ▮ TTY1 80×25(--phos-lo,通栏一行)
│ ═══ 标题行(═ 双线)═══
│ 主区:线框面板 + 字符图,左边距 2ch
│ 当前行尾:游标 ▮(530ms 闪烁)
└ 底行:命令回显 / 分页提示
四角:8% 黑径向暗角;全屏扫描线叠加(1px/3px,8%,固定)
```

### 4.3 图形母题(白名单,全部字符绘制)

1. **ASCII/Unicode 线框**:`┌─┐│└─┘` 绘面板,`═` 双线表标题栏。
2. **字符条形图**:`████████░░` 与 `▁▃▅▇` 火花线。
3. **示波轨迹**:关键数值旁附一条正弦/方波 SVG 轨迹,1px,`--phos-lo`,作为"信号"隐喻。
4. **辉光晕影**:四角轻微暗角(8% 黑径向),显像管曲率暗示。

禁止:位图图片、彩色、圆角 > 2px、无衬线黑体标题。

## 5. 数据可视化规范

| 场景 | 规定形式 | 约束 |
|---|---|---|
| 排行/比分 | 字符条 `████░░` + 数值右对齐 | 逐列点亮(§7.4);数值等宽 |
| 趋势 | 火花线 `▁▃▅▇` | 一行内,不折行 |
| 对比 | 双行 diff 式 `-` / `+` 前缀 | 本机行亮一档 |
| 负值/错误 | `--alert` + `!` 前缀 | 每屏 ≤ 2 处 |
| 表格 | 线框字符表格 | 禁止灰底;列右对齐 |

- 一切图表字符化;坐标轴用 `--phos-lo`。
- 关键数值旁可附示波轨迹(§4.3),是"信号在跳"的唯一图形化表达。

## 6. 页面类型与应用

| 页型 | 骨架 | 要点 |
|---|---|---|
| 封面 | `═` 双线大标题 + 状态栏 | 从头打字进场;游标停在标题行尾 |
| 叙事页 | 打字机正文 + 线框面板 | 逐字符打出;关键数字行亮一档 |
| 数据页 | 字符图 + 右对齐数值列 | 逐列点亮;负值 `!` 前缀告警色 |
| 实录页 | 嵌套"子终端"线框 + 示波轨迹 | 内层面板再打一遍字;REC 圆点 1s 闪烁 |
| 结束页 | logout 画面(§7.5) | 状态栏走时停止 |

## 7. 动效语言

### 7.1 节奏基调

- 打字机速度 30–60 字/秒,行间停顿 80ms。
- 时长预算:微交互 ≤ 200ms;翻页(清屏重载)≈ 300ms 内完成切换;任何单段动画 ≤ 800ms。
- 缓动:终端无缓动——线性或 steps,机械即正义。

### 7.2 签名动效:打字机

- 正文逐字符打出,30–60 字/秒,行间停顿 80ms。
- 关键数字打出后整行亮一档(`--phos` → `--phos-hi`)。
- 长页分段打:每段 ≤ 6 行,段间停顿 160ms,给观众阅读窗口。

### 7.3 翻页转场(白名单)

1. **清屏重载(默认)**:`CLEAR` → 黑屏 80ms → 新页从头打字。
2. **垂直回扫(段落切换)**:全屏扫描线滚动 200ms,随后清屏重载。

禁止:淡入淡出、滑动翻页、缩放——显像管只会清屏与回扫。

### 7.4 图表动效

- **数据图·逐列点亮**:字符条逐列从 `░` 到 `█`,每列 40ms,像采样。
- **磷光余辉**:强调元素亮起到 `--phos-hi` 后以 1.2s 指数衰减回落,像磷光余韵——本方案唯一的发光动效。

### 7.5 结束页与退场 · CRT 关机

- 结束页 = logout 画面:状态栏走时停止,逐行打出 `LOGOUT`、`SESSION TERMINATED`、总运行时长三行,游标留在行尾。
- 退场(按序执行,显像管物理的完整关机):
  1. 游标闪 3 次;
  2. 画面垂直收缩成一条水平亮线(200ms);
  3. 亮线缩成一个亮点(150ms);
  4. 亮点以磷光余辉指数衰减 1.2s 至全黑——全片辉光在此得到唯一一次主角待遇;
  5. 全黑停 ≥ 1s,供录屏切尾。
- 干净帧:全黑。

### 7.6 背景层动效(低感知阈值)

循环允许(终端是活的):
- 游标 `▮` 530ms 闪烁;
- 状态栏走时 1s 步进;
- 示波轨迹 8s 周期缓移。
其余一律静止;内容区任何元素不得自行循环。

### 7.7 降级(?noanim)

打字机直显全文;清屏重载 1 帧直切;字符条直显终值;游标闪烁、状态栏走时保留(信息载体,非装饰)。降级版信息必须完整,服务录屏截图与印刷导出。

## 8. 文案语调

- 日志体:短句、全小写命令式或全大写系统式,如 `LOADING MODULE... OK`。
- 数字先行:先打印结果,再打印解释;错误照实打印,不修饰。
- 禁止感叹号(告警用 `!` 前缀是语法,不是情绪)。

## 9. 质量清单(交付前逐项过)

1. 单色纪律?除 `--alert` 外无第二色相?`--alert` ≤ 2 处?
2. 一切元素对齐字符格?行距以整行计?
3. 每页状态栏在位?游标 `▮` 常驻当前行尾?
4. 全部图形字符绘制?无位图、无圆角 > 2px?
5. 辉光仅 `0 0 8px` 级?扫描线 8% 且固定?
6. 最小字号 ≥ 24px?正文 ≥ 28px?
7. 打字机 30–60 字/秒?单段动画 ≤ 800ms?循环仅游标/走时/示波?
8. 翻页只用清屏重载 / 垂直回扫?
9. ?noanim 版信息完整?
10. 2560×1440 截图经 H.264 压缩后,字符仍清晰可读?

## 10. 与既有方案的边界

| | 远岸(00) | 蓝图(01) | 磷光终端(本方案) |
|---|---|---|---|
| 底 | 深渊黑 | 图纸蓝 | 显像管黑 |
| 高光 | volt 荧黄绿 | 审阅洋红 | 琥珀磷光(亮一档即强调) |
| 数字 | 等宽 odometer | 等宽 + 尺寸标注 | 等宽打字机 |
| 母题 | 起点线/星野/checker | 图框/网格/引伸线 | 字符线框/扫描线/游标 |
| 动效气质 | 纪念碑静止 × 机械爆发 | 鸭嘴笔匀速绘制 | 永远在轻微地活 |
| 收尾 | 落旗断电 | 归档入柜 | CRT 关机 |

磷光与远岸同为暗底工程感,分野在"静与活":远岸停留即死寂,磷光停留即运转。任何一页若与姊妹方案签名元素撞车(起点线、图签栏),回到 §4.3 母题白名单内解决——终端里只有字符。

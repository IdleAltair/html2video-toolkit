# 设计语言 · 瑞士网格 SWISS GRID

> 版本 v1.0 · 2026-10-14

> 参照系:国际主义平面风格——数学栅格、无装饰黑体、唯一的信号红
> 姊妹方案见目录:[design-language-catalog.md](design-language-catalog.md)(本文为其方案 02 的完整版)

## 0. 主题立意

**内容即秩序。**

严格的数学栅格、无装饰的黑体、唯一的信号红。瑞士网格的力量来自克制——当一切都是白底黑字,那一点红就是全部的情绪。

两者(排版与论证)合一的公式:

> **秩序即情绪:一切归位之后,唯一的红就是结论。**

与构成主义的区别:构成主义是革命的呐喊(斜线、拼贴、水印大字),瑞士网格是**编辑部的事后总结**(正交、编号、脚注)。一个动,一个静。叙事隐喻:观众在读一份编辑部终审的专题版——每个数字都有编号,每个结论都有脚注。

---

## 1. 设计原则(五条,按优先级)

1. **栅格即法律。** 12 列栅格,列距 32px;所有元素必须咬合格线,任何"凭感觉挪 10px"禁止。
2. **三阶无色相。** 只有红、黑、灰;多场对比用灰度阶梯(100%/70%/45%/25% 黑),任何第二彩色禁止。
3. **红是结论。** 每屏 ≤ 2 处、面积 ≤ 1%;语义固定"当前/结论/否定"三选一,页内不得混用。
4. **字重压过颜色。** 对比用字重(700)与字号阶梯解决,不靠彩色。
5. **录制优先。** 字号与对比度以 2560×1440 录屏经 H.264 压缩后仍清晰为准(§9)。

## 2. 色彩系统

### 2.1 色板(token)

```css
:root{
  --paper: #FAFAF7;  /* 纸白:微暖,非纯白 */
  --ink:   #111111;  /* 文字黑 */
  --gray:  #8A8A85;  /* 次级灰 */
  --hair:  #D8D8D2;  /* 毛发线 */
  --red:   #E4032E;  /* 瑞士红:全页唯一彩色 */
}
```

### 2.2 配色约束

| 规则 | 约束 |
|---|---|
| 红用量 | 每屏 ≤ 2 处,总面积 ≤ 屏幕 1% |
| 色阶 | 只允许红、黑、灰三阶;任何第二彩色禁止 |
| 多场对比 | 用灰度阶梯:100% / 70% / 45% / 25% 黑 |
| 红语义 | 固定为"当前/结论/否定"三选一,页内不得混用 |
| 禁止 | 彩色图表、渐变、投影、图片滤色 |

### 2.3 对比度硬指标(录屏压缩后)

- 正文/底:≥ 12:1(`--ink` on `--paper` ≈ 17:1,达标)
- 次级灰/底:≥ 3:1(`--gray` on `--paper` ≈ 3.2:1,仅用于 ≥ 24px 注释与大字,正文禁用)
- 红/底:≥ 4.5:1(≈ 4.5:1,达标;红色块内白字反白时按白/红 ≥ 4.5:1 校验)

## 3. 字体与排版

### 3.1 字族

| 角色 | 字体 | 说明 |
|---|---|---|
| 西文标题 | Helvetica Now / Neue Haas Grotesk 700(备选 Inter) | 可跨栏放大,允许出血到页缘 |
| 西文正文 | 同上 400 | |
| 中文 | Noto Sans SC,字重同上(标题 700 / 正文 400) | |
| 数字 | 等宽 tabular(页码、编号、表格数字) | |

### 3.2 字号阶梯(2560×1440 基准)

| 层级 | px | 用途 |
|---|---|---|
| 巨数 | 200+ | 跨栏黑字;红只给单位或脚注编号 |
| 标题 | 120–160 | 跨栏,允许出血到页缘 |
| 小节题 | 48–64 | |
| 正文 | 30–34 | 固定 4 栏宽;硬下限 28px |
| 脚注/注释 | 24–26 | 脚注带专用;低于 24px 删除,不缩小 |
| 页码/章节编号 | 24,等宽 | `3.2` / `07/16`,挂栅格固定位 |

### 3.3 排版约束

- **栅格即设计**:12 列栅格,列距 32px;所有元素必须咬合格线。
- 标题可跨栏放大至 120–160px,允许出血到页缘;正文固定 4 栏宽。
- 每页必须有页码与章节编号,格式 `3.2` / `07/16`,挂栅格固定位,等宽数字——这是签名元素。
- 标题必须是**结论句**;名词短语只配做章节名,不配做标题。
- 斜体全方案禁止;强调用字重或红移(§7.2),不用字形倾斜。

## 4. 版式与栅格

### 4.1 画布

2560×1440,安全边距四边各 96px;内容区 2368×1248,内分 12 列、列距 32px。

### 4.2 版面结构

```
│ 左上:章节编号 `3.2`            右上:页码 `07/16`(等宽,固定位)│
│                                                            │
│   标题区(可跨 8–12 栏,允许出血)                            │
│   正文区(固定 4 栏)      │      图表区(咬合 6–8 栏)       │
│                                                            │
│ ─── 0.75px 毛发线 ────────────────────────────────────── │
│ 底部 1/6:脚注带(来源与注释,--gray,24–26px)               │
```

### 4.3 图形母题(白名单)

1. **毛发线**:0.75px `--hair` 分隔线,正交,绝不倾斜。
2. **编号圆**:红底白字小圆(直径 48px),表步骤/章节序号——全方案唯一允许的非矩形态。
3. **脚注区**:页面底部 1/6 为脚注带,毛发线隔开,放来源与注释。

禁止:斜线、斜体、投影、圆角卡片、图标装饰、图片描边。

## 5. 数据可视化规范

| 场景 | 规定形式 | 约束 |
|---|---|---|
| 对比/排行 | 黑灰阶梯矩形的精确排列 | 红色只标当前/结论项;其余走 100%/70%/45%/25% 阶梯 |
| 表格(主战场) | 毛发线表格 + 等宽数字右对齐 | 对比用字重(700)而非颜色 |
| 大数字 | 200px+ 跨栏黑字 | 红只给单位或脚注编号 |
| 流程/步骤 | 编号圆序列 + 毛发线连接 | 编号圆是唯一的圆 |
| 来源/口径 | 脚注带 | 凡数据必有脚注来源 |

- 图表不配色:除红色标记外,一切层级用灰度与字重。
- 任何图表元素必须咬合栅格;坐标轴用毛发线,不加箭头装饰。

## 6. 页面类型与应用

| 页型 | 骨架 | 要点 |
|---|---|---|
| 封面 | 跨栏巨题 + 页码 `01/16` | 一处红点到即止;无图表 |
| 论述页 | 标题 + 正文 4 栏 + 脚注带 | 红标当前论点;小节题 48–64px |
| 数据页 | 巨数或表格 + 脚注带 | 巨数 200px+;表格毛发线 + 右对齐 |
| 对比页 | 双栏灰度阶梯 + 红标结论 | 灰度四阶封顶;红每屏 ≤ 2 处 |
| 结束页 | colophon 版权页(§7.5) | 页码 `16/16` 照常落位 |

## 7. 动效语言

### 7.1 节奏基调

- 缓动:落版 `cubic-bezier(0.2,0,0,1)`(急停);翻页线性。
- 时长预算:微交互 ≤ 200ms;元素进场 300ms;翻页 360ms;任何单段动画 ≤ 800ms。
- 级联:按栅格块逐项落版,间隔 60ms,最多 6 项。

### 7.2 签名动效:排版落版 与 红移

- **排版落版**:文字按栅格块逐个"落版"——从上方 24px 落下 + 透明度 0→1,300ms,`cubic-bezier(0.2,0,0,1)`(急停),像铅字压进纸里。
- **红移**:强调转移时,旧红元素褪色为黑、新元素由黑变红,交叉 240ms——全片只有这一种"强调动画"。

### 7.3 翻页转场(白名单)

1. **推格(默认)**:沿栅格方向水平推页(右出左入),360ms,线性,无缓动花哨。
2. **整版更换(章节切换)**:旧页向下推出、新页自上落下落版,360ms;章节编号同步翻牌。

禁止:淡入淡出翻页、旋转、缩放、任何"活泼"的转场。

### 7.4 图表动效

- 数据条:从栅格左缘以步进式跳到终值——每 80ms 一跳,共 5 跳;量化感,不连续。
- 表格行:按行落版,同 §7.2;不做行高生长。

### 7.5 结束页与退场 · 版权页停格

- 结束页 = colophon:制作信息、数据来源、字体与工具 credits,按栅格排成一页编辑部版权页,页码 `16/16` 照常落位——克制到底,不煽情。
- 退场(按序执行):
  1. 全片最后一处红褪色为黑(240ms,"红移"的最后一次执行);
  2. 整页沿栅格向下推格出画(360ms 线性);
  3. 纸白空页停 1.5s,供录屏切尾。
- 干净帧:纸白 + 页码。不允许任何谢幕文字。

### 7.6 背景层动效

循环动画**全禁**。瑞士网格不允许任何东西无端动;页面停留时唯一的变化是翻页本身。

### 7.7 降级(?noanim)

落版与推格全部 1 帧直切;数据条直显终值;红移以静态终态呈现(当前项即红)。页码、章节编号、脚注照常——降级版信息必须完整,服务录屏截图与印刷导出。

---

## 8. 文案语调

- 编辑部体:判断句、编号、脚注,像终审后的专题版。
- 数字先行:先给数,再论证;论证引用脚注编号,不情绪化。
- 禁止感叹号、禁止形容词堆叠、禁止设问句带节奏。

---

## 9. 质量清单(交付前逐项过)

1. 红每屏 ≤ 2 处、面积 ≤ 1%?语义页内唯一?
2. 无第二彩色?多场对比只用灰度阶梯?
3. 所有元素咬合 12 列栅格?无凭感觉偏移?
4. 每页页码 + 章节编号(`3.2` / `07/16`)挂固定位?
5. 非矩形态只有编号圆?无斜线、斜体、投影、圆角?
6. 强调动画只有红移(240ms)一种?
7. 最小字号 ≥ 24px?正文 ≥ 28px、固定 4 栏宽?
8. 循环动画全禁?单段动画 ≤ 800ms?
9. ?noanim 版信息完整?
10. 2560×1440 截图经 H.264 压缩后,脚注文字仍清晰可读?

## 10. 与既有方案的边界

| | 构成主义(参照系) | 白盒画廊(06) | 瑞士网格(本方案) |
|---|---|---|---|
| 底 | 奶油纸 | 展墙白 | 纸白 |
| 高光 | 海报红(大面积) | 藏青(一件展品) | 瑞士红(≤ 2 处) |
| 母题 | 斜线/注册标记/水印 | 展线/展台/空墙 | 毛发线/编号圆/脚注带 |
| 密度 | 拼贴高密度 | 疏,留白 ≥ 55% | 密而有序 |
| 动效气质 | 碎裂拼贴 | 导览推移,最慢 | 落版急停,编辑部效率 |
| 收尾 | (碎裂) | 闭馆空墙 | 版权页停格 |

瑞士与白盒同为白底克制系,分野在密度与职责:白盒用空白点睛,瑞士用红点睛;白盒是凝视,瑞士是论证。任何一页若与姊妹方案签名元素撞车(斜线水印、展签),回到 §4.3 母题白名单内解决。

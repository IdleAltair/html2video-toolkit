> 版本 v1.0 · 2026-10-14

## 0. 主题立意

**内容是被策展的展品。**

展墙白、极多留白、展签式排版、博物馆级的字体排印。动效是"导览"——缓慢、笃定,像镜头在展厅里推移。全部方案中节奏最慢、最适合长文的一套。

公式:

> **用空白点睛:一件展品、一枚展签、一面空墙。**

叙事隐喻:观众被导览着走过一排展厅,每个展台只放一件展品(一个数字、一张图);展签写着它的来历。与瑞士网格的区别:瑞士是编辑部(密、编号、效率),白盒是美术馆(疏、凝视、余白)。瑞士用红点睛,白盒用**空白**点睛。

---

## 1. 设计原则(五条,按优先级)

1. **留白率 ≥ 55%。** 无任何元素的面积占比写进验收(§9);空墙就是母题。
2. **一色点题。** 藏青每屏 ≤ 1 处——一件"展品"(结论数字或一条展线)。
3. **一图一数。** 每个展台只讲一个数,图表注释 ≤ 2 行。
4. **慢是礼仪。** 展品亮灯 800ms、闭馆熄灯 1.5s 是本方案特批的"慢";除此之外不做任何多余动作。
5. **录制优先。** 浅底细线以 H.264 压缩后仍清晰为准:1px 线配 ≥ 24px 字,正文 ≥ 28px(§9)。

## 2. 色彩系统

### 2.1 色板(token)

```css
:root{
  --wall:  #F5F4F0;  /* 展墙白:中性微暖 */
  --ink:   #1A1A18;  /* 墨黑:正文 */
  --cap:   #6B6B66;  /* 展签灰:注释、图注 */
  --plinth:#E3E1DA;  /* 展台灰:面板与分隔 */
  --solo:  #1F4D8F;  /* 点题藏青:全片唯一彩色,仅结论数字与一条展线 */
}
```

### 2.2 配色约束

| 规则 | 约束 |
|---|---|
| 藏青用量 | 每屏 ≤ 1 处(一件"展品":结论数字或一条展线) |
| 色阶 | 只有 wall / plinth / cap / ink 四阶灰 + 一色 |
| 禁止 | 任何高饱和彩色、渐变、纹理 |
| 留白率 | ≥ 55%,写进验收 |

### 2.3 对比度硬指标(录屏压缩后)

- 正文/底:≥ 12:1(`--ink` on `--wall` ≈ 16:1,达标)
- 展签灰/底:≥ 4.5:1(≈ 5:1,达标,`--cap` 不得再调浅)
- 藏青/底:≥ 7:1(≈ 7.6:1,达标)
- 展台灰仅作衬底,不承载文字;其上文字用 `--ink`

## 3. 字体与排版

### 3.1 字族

| 角色 | 字体 | 说明 |
|---|---|---|
| 标题 | Noto Serif SC 600 | 字距 +0.08em,60–84px——展厅标题从不喊 |
| 正文 | Noto Sans SC 400 | 34px,行高 1.9,栏宽 ≤ 30 字 |
| 数字 | 等宽 tabular | 结论数字藏青,其余墨黑 |

### 3.2 字号阶梯(2560×1440 基准)

| 层级 | px | 用途 |
|---|---|---|
| 展厅标题 | 60–84 | 字距 +0.08em,不超过两行 |
| 展品数字 | 96–160 | 一件展品;结论值藏青 |
| 正文 | 34 | 行高 1.9,栏宽 ≤ 30 字 |
| 展签说明 | 26–28 | 三行以内,`--cap` |
| 展签序号/来源 | 24,等宽 | 低于 24px 删除,不缩小 |

### 3.3 排版约束

- **展签格式固定**:序号(等宽小字)/ 题目(衬线)/ 三行以内说明(灰)/ 数据(等宽 tabular)。位置:内容区左下,像挂在展品旁——签名元素。
- 标题必须是**陈述句**,声音压低("第四次评审之后"),禁止名词堆叠与口号。
- 正文栏宽 ≤ 30 字,行高 1.9;长文分页,不压缩行距。
- 数字等宽 tabular;单位小两档、`--cap` 色。

## 4. 版式与栅格

### 4.1 画布

2560×1440,安全边距四边各 128px(白盒边距全方案最大);内容区 2304×1184。

### 4.2 展墙结构

```
│ 上部:展厅标题(60–84px)+ 展线(1px 墨,长度 = 栏宽)     │
│ 中部:展台(--plinth 平涂)托一件展品,四围空墙            │
│ 左下:展签(序号/题目/≤3 行说明/数据)+ 钉距刻度          │
│ 留白率 ≥ 55%                                             │
```

### 4.3 图形母题(白名单)

1. **展线**:1px 墨线,水平,长度 = 栏宽,悬挂标题或分隔展区。
2. **展台**:`--plinth` 平涂矩形,托起图表这件"展品",无框无影。
3. **钉距刻度**:展签左侧 4 枚 2px 方点纵向排列,表展签序号。
4. 除此之外什么都不需要——空墙就是母题。

禁止:图标、描边卡片、checker、斜元素、任何"活泼"的东西。

## 5. 数据可视化规范

| 场景 | 规定形式 | 约束 |
|---|---|---|
| 单值强调 | 展品数字(96–160px) | 结论值藏青,每屏一件 |
| 图表 | 细线(1.5px 墨)+ 等宽标注 | 柱条 `--plinth` 填充、墨描边;结论项藏青 |
| 一图一数 | 每个展台只讲一个数 | 图表注释 ≤ 2 行 |
| 时间/流程 | 展墙序列:等距展台一字排开 | 无箭头——参观顺序即方向 |

- 图表极简;任何装饰性元素(图例框、网格底纹)拆除。
- 数值必须标注;图表服务于数字,不是反过来。

## 6. 页面类型与应用

| 页型 | 骨架 | 要点 |
|---|---|---|
| 封面 | 展厅标题 + 一条展线 | 藏青 ≤ 1 处;无展台 |
| 长文页 | 正文栏(≤ 30 字宽)+ 展签 | 留白率 ≥ 55%;慢读 |
| 展品页 | 展台 + 展品数字/图表 + 展签 | 一图一数;亮灯进场(§7.2) |
| 序列页 | 等距展台一字排开 | 无箭头;参观顺序即方向 |
| 结束页 | 最后一面展墙(§7.5) | 留白率 ≥ 70% |

## 7. 动效语言

### 7.1 节奏基调

- 缓动:导览 `cubic-bezier(0.25,0,0,1)`;其余淡入线性。
- 时长预算:元素淡入 400ms;翻页 600ms;亮灯 800ms(允许超 500ms,本方案特批的"慢");闭馆熄灯 1.5s(全方案最慢动画,特批)。除特批外单段动画 ≤ 800ms。
- 级联:展签三行依次 90ms 间隔;不做更多级联。

### 7.2 签名动效:导览推移 与 展品亮灯

- **导览推移(翻页)**:旧页以 120px 视差(背景慢、内容快)向左退场,新页从右入,600ms,`cubic-bezier(0.25,0,0,1)`,像走过一面展墙。
- **展品亮灯**:关键数据/图表进场时,展台区域亮度 +4% 渐起 800ms;其余元素淡入 400ms。

### 7.3 翻页转场(白名单)

1. **导览推移(默认)**:见 §7.2。
2. **展区切换(章节)**:镜头横移加倍(240px 视差),中间空墙停留 400ms,像拐过展厅转角。

禁止:淡入淡出翻页(太随意)、缩放、滑动弹跳。

### 7.4 图表动效

- **展签翻牌**:展签文字三行依次 90ms 间隔淡入,无位移。
- **数字·静默呈现**:不滚动不跳动,直接以藏青呈现——白盒里数字不需要表演。
- 图表线条以淡入呈现,不做绘制动效。

### 7.5 结束页与退场 · 闭馆空墙

- 结束页 = 最后一面展墙:一枚展台、一句结语、一枚展签,留白率 ≥ 70%。
- 退场(按序执行;目录通用约束对本方案特批放宽——空墙凝视的 2s 为签名收尾,不许剪辑压缩):
  1. 展台"亮灯"逆运算——亮度缓回 800ms;
  2. 展签三行按进场逆序淡出;
  3. 展线从右向左擦除 400ms;
  4. 镜头最后一次横移,停在一面**空墙**上凝视 2s(签名收尾);
  5. 整墙明度缓降至全黑(1.5s,全方案最慢动画,特批);
  6. 全片最后一点藏青在熄灯前褪成墨黑;全黑停 ≥ 1s,供录屏切尾。
- 干净帧:全黑。

### 7.6 背景层动效

循环动画**全禁**。美术馆里只有观众在动。

### 7.7 降级(?noanim)

导览推移 1 帧直切;亮灯直呈亮态;展签三行同帧呈现;数字静默呈现(原本就无动画)。留白率、展签格式照常——降级版信息必须完整,服务录屏截图与印刷导出。

---

## 8. 文案语调

- 展签体:陈述句、低声调、可引用,像博物馆图录。
- 一句一事:每句只讲一件事;长句拆两句。
- 数字不表演:先给数,展签给来历;禁止感叹号与悬念式设问。

---

## 9. 质量清单(交付前逐项过)

1. 留白率 ≥ 55%(结束页 ≥ 70%)?
2. 藏青每屏 ≤ 1 处?无第二彩色、无渐变、无纹理?
3. 展签四件齐全(序号/题目/≤3 行说明/数据)且位置左下?
4. 每个展台只讲一个数?图表注释 ≤ 2 行?
5. 数字全部等宽 tabular?结论数字藏青?
6. 无图标、描边卡片、checker、斜元素?
7. 最小字号 ≥ 24px?正文 34px、行高 1.9、栏宽 ≤ 30 字?
8. 循环动画全禁?除特批(亮灯 800ms / 熄灯 1.5s)外单段动画 ≤ 800ms?
9. ?noanim 版信息完整?
10. 2560×1440 截图经 H.264 压缩后,展签小字与 1px 展线仍清晰可读?

## 10. 与既有方案的边界

| | 瑞士网格(02) | 浮世绘现代(04) | 白盒画廊(本方案) |
|---|---|---|---|
| 底 | 纸白 | 和纸(暖米,3% 纤维) | 展墙白 |
| 高光 | 瑞士红(≤ 2 处) | 朱红(落款/结论) | 藏青(≤ 1 处) |
| 母题 | 毛发线/编号圆/脚注带 | 骨线波/云气纹/円相 | 展线/展台/空墙 |
| 密度 | 密而有序 | 疏,意象 | 最疏,留白 ≥ 55% |
| 动效气质 | 落版急停 | 版画动起来 | 导览推移,全方案最慢 |
| 收尾 | 版权页停格 | 收卷落款 | 闭馆空墙 |

白盒与瑞士同为白底克制系,分野在密度与职责:瑞士用红点睛,白盒用空白点睛;瑞士是论证,白盒是凝视。任何一页若与姊妹方案签名元素撞车(编号圆、落款印),回到 §4.3 母题白名单内解决。

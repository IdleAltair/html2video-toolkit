## 0. 主题立意

**制图室的精确 × 红笔的审阅。**

把内容当作一套**待审阅的工程图纸**。每一页是一张图签:有图框、图号、修订栏、尺寸标注。所有元素都像用鸭嘴笔和丁字尺画出来的,没有任何一笔是随手放的。

两者合一的公式:

> **数据不是被展示出来的,是被标注出来的。**

叙事隐喻:观众在翻一套竣工图。图签栏里的图号、修订、日期是档案身份;尺寸标注线把页面上的每一个数字"丈量"出来;洋红是审阅者的红笔,只圈关键处。不说"展示",说"交图"。

---

## 1. 设计原则(五条,按优先级)

1. **图签即身份。** 每页必须有图框与图签栏;缺了图签栏的页面不是图纸,是海报,直接打回。
2. **标注即语法。** 任何数据图形必须配尺寸标注(引伸线 + 数字);只画不标是废图。
3. **蓝底统治。** 任意页面 `--paper` 占比 ≥ 80%;面板只允许深一档的 `--paper-2`。
4. **洋红是红笔。** 每屏 ≤ 4 处,必须带标注形态(圈、箭头、引线);红笔不涂墙,禁止块面填充。
5. **录制优先。** 字号、线宽、对比度以 2560×1440 录屏经 H.264 压缩后仍清晰为准(§9)。

## 2. 色彩系统

### 2.1 色板(token)

```css
:root{
  --paper:   #14407A;  /* 图纸蓝:晒图纸底,哑光,平涂 */
  --paper-2: #0F3468;  /* 面板底:深一档 */
  --line:    #DCE8F5;  /* 制图线白:主要线条与文字 */
  --line-dim:#7FA0C4;  /* 次要线:网格、刻度、注释 */
  --mark:    #FF4FA3;  /* 审阅洋红:圈注、修订标记、关键值 */
  --ok:      #7DF0C8;  /* 验收青:通过/正确/达标,仅状态语义 */
}
```

### 2.2 配色约束

| 规则 | 约束 |
|---|---|
| 主底覆盖率 | 任意页面 `--paper` 占比 ≥ 80% |
| 洋红用量 | 每屏 ≤ 4 处,且必须带标注形态(圈、箭头、引线),禁止块面填充 |
| `--ok` 语义 | 仅状态语义(通过/正确/达标),以 12px 状态点出现,不作图形用色 |
| 第三色相 | 黄、绿、紫全禁;画面只允许蓝、白、洋红与 `--ok` 状态点 |
| 禁止 | 实色块面(除 `--paper-2` 面板底)、渐变、发光、阴影、圆角、手绘线条 |

### 2.3 对比度硬指标(录屏压缩后)

- 正文/底:≥ 7:1(`--line` on `--paper` ≈ 8:1,达标)
- 次要线/底:≥ 3:1(`--line-dim` on `--paper` ≈ 3.8:1,仅用于 ≥ 24px 注释与图形线,正文禁用)
- 洋红/底:≥ 3:1(≈ 3.4:1;洋红线宽 ≥ 2px,不作小字号正文)
- 主图与面板底:`--line` on `--paper-2` ≈ 10:1,面板内层级不得再降

## 3. 字体与排版

### 3.1 字族

| 角色 | 字体 | 说明 |
|---|---|---|
| 英文/数字/单位 | Space Mono(备选 IBM Plex Mono) | 等宽制图字;图签栏英文全部大写 |
| 中文标题 | Noto Sans SC 700 | 白色;制图字没有超粗,禁止 900 |
| 中文正文 | Noto Sans SC 500 | 行高 1.7 |

### 3.2 字号阶梯(2560×1440 基准)

| 层级 | px | 用途 |
|---|---|---|
| Hero 数字 | 120–160 | 图面结论值,必须配尺寸标注 |
| 图题(页标题) | 64–80 | 一句话结论式标题 |
| 面板标题 | 36–40 | 允许全大写英文 |
| 正文 | 30–34 | 硬下限 28px |
| 注释/刻度 | 24–26 | 低于 24px 的内容删除,不缩小 |
| 图签栏 | 24,等宽大写 | 图号/比例/修订/日期 |

### 3.3 排版约束

- **图签栏(标题块)固定在右下**:图号 `DWG-01/27`、比例 `1:1`、修订 `REV A`、日期——每页必填,这是签名元素。框外左上角另标图号,与图框配套(§4.3)。
- 标题必须是**结论句**("主管线压降 12%"),禁止名词短语式标题("管路分析")。
- 标注文字允许 90° 旋转竖排(图纸惯例);其余文字一律水平。
- 数字等宽 tabular;单位小两档、`--line-dim` 色,与数字基线对齐。
- 单行不超过 40 字;注释挂在标注线末端,不悬空右飘。

## 4. 版式与栅格

### 4.1 画布

2560×1440,图框即安全框:四边各 64px。内容区 2432×1312。

### 4.2 图面结构

```
┌─ 图框(1.5px --line 内框,四边 64px)────────────────────────┐
│(框外左上)图号                     右上:修订栏 REV A · 日期│
│                                                            │
│   主图区(图表 + 尺寸标注,约 75%)          │ 注释列(25%) │
│                                                            │
│                                          右下:图签栏       │
└────────────────────────────────────────────────────────────┘
背景:96px 方格网格,1px --line-dim、透明度 18%;主网格每 4 格加粗一次
```

- **图框**:每页 1.5px `--line` 白线内框,四边留 64px;所有内容不得出框。
- **注释列**:右侧 1/4,放图例、数据来源、修订说明,`--line-dim` 为主。

### 4.3 图形母题(白名单)

1. **图框**:每页 1.5px 白线内框,四边留出 64px;框外左上角落图号。
2. **网格**:背景 96px 方格,1px `--line-dim`、透明度 18%;主网格每 4 格加粗一次。
3. **尺寸标注**:带端点箭头的引伸线 + 数字,用来"丈量"页面上的数据——条形图的长度、数值的落差,都必须用标注线标出,这是本方案的核心语法。
4. **虚线与剖面线**:虚线表"隐藏/推断",45° 剖面线填充表"截断面",语义固定不得挪用。

禁止:实色块面(除面板底)、圆角、阴影、渐变、任何手绘风元素。

## 5. 数据可视化规范

| 场景 | 规定形式 | 约束 |
|---|---|---|
| 柱状/排行 | 剖面线填充矩形 + 顶部长度标注 | 排线逐根画出(§7.4);数字必须在标注线上 |
| 对比/落差 | 两矩形间落差引伸线 + Δ 值 | 关键落差用洋红圈注,计入每屏 ≤ 4 处洋红 |
| 时间 | 水平尺度尺 | 刻度等距,数字挂刻度下方,`--line-dim` |
| 达标/通过 | `--ok` 12px 状态点 + 文字 | 仅状态语义,不放大成图 |
| 表格 | 1px `--line-dim` 线框表格 | 等宽数字右对齐,表头全大写 |

- **数字必须出现在标注线上**,不允许只画不标——这是本方案与一切"看着给"的图表的分界线。
- 虚线与剖面线语义固定(§4.3),不得借去表达"预测走势"以外的含义。

## 6. 页面类型与应用

| 页型 | 骨架 | 要点 |
|---|---|---|
| 封面 | 图框 + 中央大标题 + 图号 `DWG-00` | 标题随轮廓线绘制进场;洋红 ≤ 1 处 |
| 数据页 | 主图区 + 注释列 + 图签栏 | Hero 数字必配尺寸标注;换页瞬间图签栏翻牌更新图号 |
| 拆解页 | 主视图 + 洋红圈注引出的局部放大框 | 放大框沿用图框语法(1.5px 线、直角),与主图以引伸线相连 |
| 段落分隔页 | 整页一张空白图签 + 段落名 | 仅图框、网格、图签栏三件套;5 秒内读完即走 |
| 结束页 | 竣工图(§7.5) | 中央大号图签栏 + 全片数据清单,无图表 |

## 7. 动效语言

### 7.1 节奏基调

- 缓动:绘制类**恒速线性**(机械笔速,约 800px/s);弹定类用 `steps`。
- 时长预算:微交互 ≤ 200ms;元素进场 300–600ms;翻页转场 400ms。**任何单段动画 ≤ 800ms**;线条绘制时长 = 线长 ÷ 800px/s,超预算的长线分段绘制。
- 级联:同组元素按绘图顺序依次进场,间隔 80ms,最多 6 项,超出则整体同入。

### 7.2 签名动效:绘制

- 所有线条与图形以"绘制"方式进场——`stroke-dashoffset` 从全虚到实,速度恒定(机械笔速,约 800px/s),像笔走过去。
- 文字在所属线条画完后 100ms 内出现,不做自己的动画——文字是被图带出来的。
- 同一元素的多条线按"先轮廓、后标注"的顺序;标注线先于标注数字。

### 7.3 翻页转场(白名单)

1. **换图(默认)**:整页向下平移出画、新页从上平移入画(换图纸动作),400ms,线性;换图瞬间图签栏先翻牌更新图号。
2. **圈注深入(局部放大)**:旧页洋红圈注圈定局部(600ms 匀速)→ 换图 400ms → 新页为该局部放大图。仅用于拆解链路。

禁止:淡入淡出翻页、旋转、缩放弹跳、任何手绘抖动。

### 7.4 图表动效

- **数据条·排线填充**:不做生长——剖面线从左到右逐根画出,每根 40ms,矩形轮廓先行。
- **标注弹定**:引伸线先画出(800px/s),数字以 `steps(2)` 跳到位,带 1 次 60ms 顿感,像盖章。
- **圈注**:洋红圈注用椭圆路径绘制 600ms,匀速,手绘感禁止。

### 7.5 结束页与退场 · 归档入柜

- 结束页 = 一张"竣工图":中央大号图签栏,结论一句话 + 全片数据清单(等宽小字),无图表。
- 退场(按序执行):
  1. 洋红"竣工"章以 `steps(2)` 跳盖在图签栏上,带 1 次 60ms 顿感;
  2. 全图线条按进场的**逆序**从右向左擦除(绘制的逆运算,800px/s);
  3. 只剩图框与图签栏;
  4. 整张图纸向下平移出画(收入图柜,400ms 线性);
  5. 网格独留 600ms;
  6. 蓝底定格 ≥ 1s,供录屏切尾。
- 干净帧:图纸蓝底 + 网格,无文字。

### 7.6 背景层动效(低感知阈值)

- 网格呼吸:透明度 18% ↔ 19%,周期 20s,仅此一项允许循环。
- 除此之外,任何停留超过 1s 的页面必须绝对静止。

### 7.7 降级(?noanim)

绘制全部直呈完成态;翻页 1 帧直切;排线填充直接给完成剖面;圈注与"竣工"章直接呈现。图框、图签栏、图号、修订信息照常——降级版信息必须完整,服务录屏截图与印刷导出。

## 8. 文案语调

- 图签体:短句、术语、可编号,像图纸附注与变更单。
- 标注先行:先给数字与位置,再解释;解释文字挂在标注下,不喧宾夺主。
- 禁止感叹号与形容词堆叠;修订记录式措辞("REV A:更新压降数据")。

---

## 9. 质量清单(交付前逐项过)

1. 蓝底占比 ≥ 80%?无第三色相(`--ok` 仅状态点)?
2. 洋红 ≤ 4 处且全部带标注形态?无块面填充?
3. 每页图框 + 图签栏(图号/比例/修订/日期)齐全?
4. 每个数据图形都配尺寸标注,数字在标注线上?
5. 全部数字等宽 tabular?单位小两档?
6. 无圆角、阴影、渐变、手绘元素?
7. 最小字号 ≥ 24px?正文 ≥ 28px?
8. 绘制动画恒速 800px/s?单段动画 ≤ 800ms?循环仅网格呼吸?
9. ?noanim 版信息完整?
10. 2560×1440 截图经 H.264 压缩后,标注文字仍清晰可读?

## 10. 与既有方案的边界

| | 远岸(00) | 磷光终端(03) | 蓝图(本方案) |
|---|---|---|---|
| 底 | 深渊黑 | 显像管黑 | 图纸蓝 |
| 高光 | volt 荧黄绿 | 琥珀磷光 | 审阅洋红 |
| 数字 | 等宽 odometer | 等宽打字机 | 等宽 + 尺寸标注 |
| 母题 | 起点线/星野/checker | 字符线框/扫描线 | 图框/网格/引伸线 |
| 动效气质 | 纪念碑静止 × 机械爆发 | 永远在轻微地活 | 鸭嘴笔匀速绘制 |
| 收尾 | 落旗断电 | CRT 关机 | 归档入柜 |

蓝图与远岸同为冷静工程感,分野在底色(蓝 vs 黑)与语法(标注 vs 遥测):远岸的数字是"报"出来的,蓝图的数字是"量"出来的。任何一页若与姊妹方案的签名元素撞车(起点线、字符线框、红移),回到 §4.3 母题白名单内解决。

# 设计语言 · 合成波 SYNTHWAVE

> 版本 v1.0 · 2026-10-14
> 适用:llm-html2video 动态网页演示(2560×1440 录屏,键盘翻页,单文件 HTML)
> 参照系:1980s 想象的未来——落日、铬字、地平网格
> 姊妹方案见目录:[design-language-catalog.md](design-language-catalog.md)(本文为其方案 05 的完整版)

## 0. 主题立意

**落日 × 铬字 × 地平网格。**

这是全部方案里唯一允许"张扬"的一套——渐变、辉光、铬面全解禁,因为它们是风格本体。节奏快、能量高,为 BGM 驱动的蒙太奇而生。

公式:

> **一切都在向地平线运动;落日是锚,网格是速度。**

叙事隐喻:这不是演示,是一支 MV。观众坐在一辆驶向落日的车里,数据是迎面冲来的路牌。与 P3R 的区别:P3R 是日式游戏 UI(静帧海报式构图),合成波是 MV(一切都在向地平线运动)。

---

## 1. 设计原则(五条,按优先级)

1. **轴心对称。** 落日永远在画面正中、悬于地平线;内容左右两列挂两侧,底部留 1/3 给网格地。
2. **霓虹分工。** 品红 = 过去/基准/他者,青 = 当前/本机/结论;两色必须成对出现,全片不换。
3. **张扬有边界。** 渐变、辉光、铬面全解禁——但辉光只属于霓虹元素,铬字不带辉光;落日橙只属于太阳。
4. **常动许可。** 本方案默许循环动(网格流动、星点、落日微浮);"静止纪念碑"在这里不成立。
5. **录制优先。** 霓虹辉光在小字号上会被 H.264 吃掉:正文 ≥ 28px、注释 ≥ 24px 是硬下限(§9)。

## 2. 色彩系统

### 2.1 色板(token)

```css
:root{
  --dusk:   #0D0418;  /* 暮空黑紫 */
  --sky:    linear-gradient(#0D0418, #2B0F4C 55%, #FF2E88 100%); /* 落日天:全方案唯一大渐变 */
  --chrome: #E8F4FF;  /* 铬白:标题 */
  --pink:   #FF2E88;  /* 品红霓虹 */
  --cyan:   #2EE6FF;  /* 青霓虹 */
  --sun:    #FFB02E;  /* 落日橙:仅落日本体 */
  --grid:   #FF2E88;  /* 地平网格同品红,透明度 40% */
}
```

### 2.2 配色约束

| 规则 | 约束 |
|---|---|
| 霓虹分工 | 品红/青必须成对出现:品红 = 过去/基准/他者,青 = 当前/本机/结论 |
| 辉光 | 只属于霓虹元素;铬字不带辉光 |
| 落日橙 | 只属于太阳,禁止挪用 |
| 大渐变 | `--sky` 是全方案唯一大渐变,只作天空背景 |
| 第三霓虹色 | 禁止;星点为铬白,不算霓虹 |

### 2.3 对比度硬指标(录屏压缩后)

- 铬白/暮空:≥ 12:1(≈ 17:1,达标)
- 青/暮空:≥ 10:1(≈ 12.7:1,达标)
- 品红/暮空:≥ 4.5:1(≈ 5.5:1,达标;品红不作小字号正文)
- 正文一律铬白或青;品红仅图形与大字

## 3. 字体与排版

### 3.1 字族

| 角色 | 字体 | 说明 |
|---|---|---|
| 标题 | Outfit / Orbitron 800 + `italic` + 6° 斜置 | 铬面纵向渐变(白→浅蓝→白),描 1px 暮紫边 |
| 数字 | Orbitron tabular | 数值铬白等宽挂光柱顶(§5) |
| 正文 | Noto Sans SC 400 | |

### 3.2 字号阶梯(2560×1440 基准)

| 层级 | px | 用途 |
|---|---|---|
| 铬字大标题 | 96–140 | 6° 斜置,轴心附近 |
| Hero 数值 | 120–180 | Orbitron tabular,青或铬白 |
| 面板数值 | 48–64 | |
| 正文 | 30–34 | 硬下限 28px |
| 注释 | 24–26 | 低于 24px 删除,不缩小 |

### 3.3 排版约束

- **构图对称轴心**:落日永远在地平线正中,内容左右两列挂两侧,底部留 1/3 给网格地。
- 标题必须是短句,≤ 12 字;MV 不读长句。
- 每页信息 ≤ 3 个数据点;塞不下就切两页——本方案为蒙太奇,不为细读。
- 衬线字体禁止(含中文宋体);纸纹理禁止。

## 4. 版式与栅格

### 4.1 画布

2560×1440,安全边距四边各 96px;地平线固定在画面下 1/3 线。

### 4.2 舞台结构

```
│ 暮空上部 1/3:星点 + 铬字标题(6° 斜置,以中轴对称)       │
│ 中轴:条纹落日悬于地平线正中;内容左右两列挂两侧           │
│ 下部 1/3:透视地平网格(品红 40%,向消失点收束)           │
```

### 4.3 图形母题(白名单)

1. **条纹落日**:正圆落日被 4–6 条水平缝切割,悬于地平线。
2. **透视地平网格**:品红网格向消失点收束,动画中向观众流动。
3. **铬框**:内容面板用 1px 铬渐变边框 + 2px 圆角(全方案唯一圆角)。
4. **星**:暮空散布 1–2px 星点。

禁止:平面直角网格(透视才合法)、衬线、纸纹理、第三霓虹色。

## 5. 数据可视化规范

| 场景 | 规定形式 | 约束 |
|---|---|---|
| 柱状/排行 | 透视光柱(立于地平线,向天生长) | 数值铬白等宽挂光柱顶 |
| 对比 | 双霓虹 | 本机/结论恒青,对照恒品红,全片不换 |
| 时间轴 | 网格道数 | 道 = 时间单位,不另画轴 |
| 单值强调 | Hero 数值 + 霓虹点亮 | 每页至多 1 个 Hero |

- 一切图表立在地平线上;数值必须同时以文字标注,禁止"只给光柱不给数"。
- 图表随透视:近大远小,不做平面直角坐标系。

## 6. 页面类型与应用

| 页型 | 骨架 | 要点 |
|---|---|---|
| 封面 | 铬字大标题 + 落日 + 网格 | 标题点亮进场;无面板 |
| 高光页 | Hero 数值 + 光柱 | ≤ 3 个数据点;霓虹点亮 |
| 对比页 | 双霓虹光柱左右排开 | 青右品红左,全片固定 |
| 段落页 | 段落切换 = 落日落半格再升起 | 配 BGM 节拍 |
| 结束页 | 驶向落日(§7.5) | 无面板无数据 |

## 7. 动效语言

### 7.1 节奏基调

- 缓动:冲入 `cubic-bezier(0.1,0.8,0.3,1)`;网格流动恒速线性。
- 时长预算:进场 500ms;翻页 450ms;点亮 300ms;任何单段动画 ≤ 800ms。
- 节奏跟 BGM:切换点卡节拍,剪辑点写进分镜。

### 7.2 签名动效:驶向地平线

- 地平网格以 400px/s 向观众流动(透视平移循环)。
- 所有进场元素沿透视方向由小放大冲入——从地平线 30% 缩放到 100%,500ms,`cubic-bezier(0.1,0.8,0.3,1)`。

### 7.3 翻页转场(白名单)

1. **换轨(默认)**:整页沿透视轴推远消失 + 新页从地平线冲来,450ms。
2. **段落切换**:加落日一次"落半格再升起",与换轨同帧开始。

禁止:横向滑动、翻书、淡化——运动方向只有透视轴。

### 7.4 图表动效

- **数据条·光轨**:条形以青/品红光轨拖尾画出,头部辉光,600ms。
- **霓虹点亮**:标题与关键值以"点亮"进场——从暮紫描边到霓虹全亮 300ms,带 1 次 100ms 电压不稳闪烁。

### 7.5 结束页与退场 · 日落收光

- 结束页 = 驶向落日:无面板无数据,铬字一句话悬在落日上方,网格常流。
- 退场(按序执行):
  1. 网格流速 ×3(镜头加速);
  2. 落日向地平线以下沉降,天空随之一路压暗(粉→紫→暮黑,1s);
  3. 铬字与霓虹以"电压不稳"闪烁 2 次后熄灭;
  4. 网格流减速至静止;
  5. 全黑前留一条品红地平线 1s;
  6. 地平线渐隐 400ms;全黑停 ≥ 1s,供录屏切尾。
- 干净帧:全黑。**BGM 尾奏应卡在落日没线的一帧,剪辑点写进分镜。**

### 7.6 背景层动效

循环允许(本方案默许常动):
- 网格流动(400px/s,透视平移);
- 星点闪烁(3 颗,错峰 4s);
- 落日微浮(±6px / 8s)。
内容面板不循环。

### 7.7 降级(?noanim)

冲入与换轨 1 帧直切;光轨直显终值;霓虹点亮直显全亮;网格流动、星点、落日微浮全部静止。落日、网格、双霓虹分工照常——降级版信息必须完整,服务录屏截图与印刷导出。

---

## 8. 文案语调

- MV 字幕体:短句、断句、大写感;一句一个画面。
- 数字先行:先冲出来数,路牌式命名("LAP 03 · 2:41")。
- 允许一处口号式修辞;禁止段落式解释。

## 9. 质量清单(交付前逐项过)

1. 落日居中、地平线在下 1/3 线?构图轴心对称?
2. 霓虹分工正确(青 = 当前/本机/结论,品红 = 过去/基准/他者)且全片未换?
3. 落日橙只在太阳?第三霓虹色为零?
4. 辉光只在霓虹元素?铬字无辉光?
5. 每页信息 ≤ 3 个数据点?
6. 圆角仅铬框 2px?无平面直角网格、无衬线?
7. 最小字号 ≥ 24px?正文 ≥ 28px?
8. 单段动画 ≤ 800ms?循环仅网格/星点/落日?
9. ?noanim 版信息完整?
10. 2560×1440 截图经 H.264 压缩后,霓虹描边小字仍清晰可读?

## 10. 与既有方案的边界

| | P3R(参照系) | 磷光终端(03) | 合成波(本方案) |
|---|---|---|---|
| 底 | 钴蓝亮底 | 显像管黑 | 暮空黑紫 + 落日天渐变 |
| 高光 | 水青 | 琥珀磷光 | 品红/青双霓虹 |
| 母题 | 斜切光束 | 字符线框/扫描线 | 条纹落日/透视网格/铬框 |
| 构图 | 静帧海报式 | 字符格 | 轴心对称 + 透视纵深 |
| 动效气质 | 持续游戏感 | 永远在轻微地活 | 一切向地平线运动 |
| 收尾 | 沉海 | CRT 关机 | 日落收光 |

合成波与磷光同为暗底发光系,分野在单色与双色、字符与透视:磷光没有纵深,合成波全是纵深。任何一页若与姊妹方案签名元素撞车(斜切光束、扫描线),回到 §4.3 母题白名单内解决。

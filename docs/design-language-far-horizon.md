## 0. 主题立意

**远视主义 × 未来主义。**

远视主义(Cosmism 一脉)回答"看什么":望向地平线之外——深空、长尺度时间、纪念碑式的静穆。它给这套语言**尺度与静止**。
未来主义(Futurism 一脉)回答"怎么动":速度、机械、爆发力、对动态的崇拜。它给这套语言**节奏与能量**。

两者合一的公式:

> **纪念碑式的静止,被机械式的爆发打断。**

画面 90% 的时间是近乎纹丝不动的"纪念碑"——近黑深空底、巨大的冷白字、克制的单色高光;剩下 10% 是翻页、数字滚动、扫描生长等短促的机械运动。静止衬托爆发,爆发回到静止。这是与 P3R(持续的游戏化动感)和构成主义(纸面静态张力)都不一样的第三种气质:**冷静的遥测播报,像一座会说话的纪念碑**。

叙事隐喻:一场 AI 对抗赛被当作一次深空任务的遥测档案来回放。分数是轨道参数,名次是信标排序,token 是燃料账。不说"比赛",说"任务日志"。

## 1. 设计原则(五条,按优先级)

1. **静止是默认态。** 任何元素没有理由不得持续运动。循环动画只允许出现在背景层,且幅度必须低于感知阈值(见 §7.5)。
2. **数字是主角。** 每页的视觉重心必须是一个或一组数字(分数、名次、token、分钟)。文字说明服务于数字,不得反过来。
3. **一处高光纪律。** 每屏主高光色(volt 荧黄绿)出现不超过 3 处。高光是稀缺资源,用在"本页结论"上。
4. **直边直角,拒绝圆润。** 全部元素 0 圆角或 2px 圆角。禁止卡片阴影、渐变发光、毛玻璃。纪念碑不发光。
5. **录制优先。** 一切规格以 2560×1440 录屏、压缩后仍清晰为准:字号、对比度、线宽都有硬下限(§9)。

## 2. 色彩系统

### 2.1 色板(token)

```css
:root{
  /* 底与面板 */
  --abyss:   #07090D;  /* 主底:深渊黑,带极轻蓝相。铺全屏 */
  --panel:   #0E1319;  /* 面板底:比主底亮一档,仅用于数据面板 */
  --edge:    #1C242E;  /* 描边/分隔线,1–2px 使用 */

  /* 文字 */
  --bone:    #E8ECE9;  /* 主文字:骨白,冷调 */
  --dim:     #6E7A86;  /* 次要文字、刻度、注释 */

  /* 高光与信号 */
  --volt:    #D6FF3F;  /* 主高光:荧黄绿。结论数字、当前项、进度 */
  --signal:  #FF5C1F;  /* 信号橙:负值、故障、本机标记、警告 */

  /* 中性数据 */
  --steel:   #3A4654;  /* 中性数据条(他者数据) */

  /* 三场任务主题色(仅在该场页面生效) */
  --m-land:  #7DF0C8;  /* 圈地:薄荷青 */
  --m-bomb:  #FFB13F;  /* 炸弹人:琥珀橙 */
  --m-flag:  #B78CFF;  /* 夺旗:电紫 */
}
```

### 2.2 配色约束

| 规则 | 约束 |
|---|---|
| 主底覆盖率 | 任意页面 `--abyss` 占比 ≥ 70%,纪念碑需要空旷 |
| volt 用量 | 每屏 ≤ 3 处,且总面积 ≤ 屏幕 3% |
| signal 橙语义 | 只表达"负/错/本机/警告"四类,禁止装饰性使用 |
| 三场色范围 | 只染:页眉标签、进度条、图表中属于本场的强调元素。骨架保持 volt,不做整场换肤 |
| 禁止 | 大面积渐变底、彩色发光、镭射/全息渐变、霓虹描边字 |

### 2.3 对比度硬指标(录屏压缩后)

- 正文 / 底:≥ 7:1(--bone on --abyss ≈ 15:1,达标)
- 次要文字 / 底:≥ 4.5:1(--dim on --abyss ≈ 5.6:1,达标,--dim 不得再调暗)
- volt / 底:≥ 10:1(≈ 17:1,达标)
- 图表相邻色:明度差 ≥ 25%,不允许仅靠色相区分

## 3. 字体与排版

### 3.1 字族

| 角色 | 字体 | 说明 |
|---|---|---|
| 数字 / 英文 / 单位 | IBM Plex Mono(备选 JetBrains Mono) | 一律 tabular figures;分数、token、计时码专用 |
| 中文标题 | Noto Sans SC 900 | 字距 -0.02em,左对齐 |
| 中文正文 | Noto Sans SC 400/500 | 行高 1.7 |

等宽数字是这套语言的签名:P3R 与构成主义都用黑体数字,远岸的所有度量都像遥测终端一样等宽跳动。

### 3.2 字号阶梯(2560×1440 基准)

| 层级 | px | 用途 |
|---|---|---|
| Hero 数字 | 144–200 | 每页结论数字,volt 或 bone |
| 页标题 | 72–96 | 一句话结论式标题 |
| 面板标题 | 36–40 | |
| 正文 | 30–34 | 硬下限 28px,录屏压缩后仍需可读 |
| 注释/刻度 | 24–26 | 低于 24px 的内容删除,不缩小 |
| 计时码/角标 | 24,等宽 | |

### 3.3 排版约束

- 标题必须是**结论句**("−346 变 −52"),禁止名词短语式标题("第三场结果")。
- 单行不超过 40 字;注释一律左对齐挂数字下方,不右飘。
- 单位("万""分钟""tok")比数字小两档、--dim 色,与数字基线对齐。

## 4. 版式与栅格

### 4.1 画布

2560×1440,安全边距四边各 96px(录屏出血)。内容区 2368×1248。

### 4.2 三分结构

```
│(起点线)│   主区(结论+图表,约 70%)   │ 遥测栏(右上,约 30%) │
│  底部:计时导航条,高 56px,通栏                          │
```

- **起点线**:页面左缘内 96px 处,2px volt 竖线,带 8px 刻度齿(每 96px 一齿)。所有页共享,是翻页动效的锚点。
- **遥测角标**:右上角常驻。内容 = 场次编号(等宽)+ 本场色 12px 方块 + 走时计时码 `00:00:00`。
- **底部计时条**:volt 填充指示进度,每页一个刻度齿;当前段脉冲一次后常亮。

### 4.3 图形母题(只允许这三种)

1. **地平线**:一条 1px --edge 横线贯穿页面下 1/3 处,纪念碑的"地面"。
2. **点阵星野**:背景 4px 圆点、间距 64px、--edge 色、透明度 6–10%。关键数字出现时,其身后 400px 半径内点阵点亮至 25% 后回落。
3. **方格旗**:8×8 黑白 checker。只允许出现在:大段落转场、最终页。不作装饰。

禁止:斜切光束(P3R 的)、斜向拼贴与水印大字(构成主义的)、圆、弧。

## 5. 数据可视化规范

| 场景 | 规定形式 | 约束 |
|---|---|---|
| 排行/比分 | 水平条 | 他者 --steel,本机 --signal,云端最高 --bone;基线 0 用 1px bone 竖线,先闪 2 次再常亮 |
| 大数字对比 | odometer 数字 | 见 §7.2;单位小两档 |
| 时间账 | 水平计时条 | 刻度齿每 10 分钟一格;本机条 signal 橙 |
| 单值强调 | Hero 数字 + 点阵点亮 | 每页至多 1 个 Hero |
| 表格 | 无框线,行分隔用 1px --edge | 列对齐用等宽数字右对齐 |

- 所有图表数值必须同时以文字数字标注,禁止"只给长度不给数"。
- 负值必须 --signal 橙,正值默认 --bone,不得用红绿隐喻涨跌。

## 6. 页面类型与应用

| 页型 | 骨架 | 要点 |
|---|---|---|
| 封面 | Hero 标题 + 起点线 + 星野 | 标题分两次落位(先中文后数据行);无 checker |
| 数据页 | 三分结构 | 结论数字 volt;注释 bone;遥测角标走时 |
| 对战/实录页 | 主区嵌实录窗口(2px --edge 描边,无圆角) | 实录窗外侧挂 REC 角标(等宽 + signal 圆点,1s 闪烁) |
| 段落分隔页 | 整页只留段落名 + checker wipe 进入 | 5 秒内可读完,读完即走 |
| 最终页"完" | checker 落旗 → 逐个断电熄灭(§7.4) | 计时码停在总时长,2s 后全黑 |

## 7. 动效语言

### 7.1 节奏基调

- 缓动:出场 `cubic-bezier(0.16,1,0.3,1)`(快入慢出);机械类(计时、扫描)用线性或 steps。
- 时长预算:微交互 ≤ 200ms;元素进场 300–500ms;翻页转场 ≤ 500ms;段落转场 ≤ 800ms。**任何动画不得超过 800ms。**
- 级联:成组元素逐项延迟 60ms,最多 6 项,超出则整体同入。

### 7.2 签名动效:odometer 数字

- 从 0 或上一页旧值滚至目标值,600ms,线性。
- 末两位用 `steps(1)` 80ms 卡顿滚动,模拟机械计数器。
- 滚到负值:落定瞬间数字变 --signal 橙,身后点阵同步闪橙 200ms,仅一次。
- 同一页多个 odometer 时,按视觉权重依次启动,间隔 120ms。

### 7.3 翻页转场(白名单,三种)

1. **Whip cut(默认)**:旧页 60px 水平移出 + 1 帧 volt 扫描线,新页反向 40px 滑入。320ms。
2. **Checker wipe(段落切换)**:方格旗对角线逐格覆盖再揭开。500ms。
3. **Shutter(同场连续页)**:上下墨黑板夹合夹开。240ms。

禁止:淡入淡出作为翻页(太软)、旋转、缩放弹跳、路径飞入。

### 7.4 图表动效

- 条形图不做"生长",做**扫表**:volt 扫描头从左扫过,条跟随落定,头部留 4px 亮拖尾,700ms 线性;本机条落定后 signal 橙呼吸 2 次(400ms×2)即止。
- 基线先闪后亮,早于数据条 200ms。

### 7.5 背景层动效(低感知阈值)

- 星野呼吸:透明度 6%↔10%,周期 12s,仅此一项允许循环。
- 遥测计时码 1s 步进走时。
- REC 圆点 1s 闪烁。
- 除此之外,任何停留超过 1s 的页面必须是绝对静止的。

### 7.6 降级(?noanim)

转场全部 1 帧直切;odometer 直显终值;扫表变静态条;呼吸与计时码保留(信息载体,非装饰)。降级版必须同样信息完整,服务录屏截图与印刷导出。

## 8. 文案语调

- 播报体:短句、陈述、克制,像任务日志。允许"正赛这版 · 局部袋子"这类档案式标注。
- 数字先行:先给数,再解释。禁止感叹号,禁止形容词堆叠("惊人地""碾压")。
- 本机一律称"本地 27B",不带情绪;失误照实标注,纪念碑不避讳失败。

## 9. 质量清单(交付前逐项过)

1. 主底占比 ≥ 70%?volt ≤ 3 处?
2. 每页有且仅有一个视觉重心数字?
3. 全部数字等宽 tabular?单位小两档?
4. 无圆角 >2px、无阴影、无发光、无渐变底?
5. 最小字号 ≥ 24px?正文 ≥ 28px?
6. 动画无超过 800ms 者?循环动画仅星野/计时码/REC?
7. 三场色未越界到骨架?signal 橙仅四类语义?
8. 翻页只用三种白名单转场?
9. ?noanim 版信息完整?
10. 2560×1440 截图经 H.264 压缩后,所有文字仍清晰可读?

## 10. 与既有两版的边界

| | P3R 钴蓝 | 构成主义奶油纸 | 远岸(本方案) |
|---|---|---|---|
| 底 | 钴蓝亮底 | 奶油纸 | 深渊黑 |
| 高光 | 水青 | 海报红 | volt 荧黄绿 |
| 数字 | 黑体 | 黑体+投影 | 等宽 odometer |
| 母题 | 斜切光束 | 斜线/注册标记/水印 | 起点线/星野/checker |
| 动效气质 | 持续游戏感 | 碎裂拼贴 | 纪念碑静止 × 机械爆发 |
| 收尾 | 沉海 | (碎裂) | 落旗断电 |

任何一页若与左两列的任一签名元素撞车,回到 §4.3 母表白名单内解决。

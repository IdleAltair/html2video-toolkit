# 01 · 蓝图 Blueprint

## 立意

把内容当作一套**待审阅的工程图纸**。每一页是一张图签:有图框、图号、修订栏、尺寸标注。气质是"制图室的精确"——所有元素都像是用鸭嘴笔和丁字尺画出来的,没有任何一笔是随手放的。

叙事隐喻:观众在翻一套竣工图。数据不是"展示"出来的,是被**标注**出来的。

## 色板

```css
:root{
  --paper:   #14407A;  /* 图纸蓝:晒图纸底,哑光,平涂 */
  --paper-2: #0F3468;  /* 面板底:深一档 */
  --line:    #DCE8F5;  /* 制图线白:主要线条与文字 */
  --line-dim:#7FA0C4;  /* 次要线:网格、刻度、注释 */
  --mark:    #FF4FA3;  /* 审阅洋红:圈注、修订标记、关键值 */
  --ok:      #7DF0C8;  /* 验收青:通过/正确/达标,仅状态语义 */
}
```

约束:洋红是"红笔",每屏 ≤ 4 处且必须带标注形态(圈、箭头、引线),禁止块面填充;蓝底占比 ≥ 80%;禁止任何第三色相进入(黄、绿、紫全禁,--ok 仅状态点)。

## 字体与排版

- 英文/数字:等宽制图字(Space Mono / IBM Plex Mono),全部大写英文用于图签栏。
- 中文:Noto Sans SC 500/700,白色,不加粗到 900(制图字没有超粗)。
- 所有标注文字 90° 可旋转,允许竖排标注(图纸惯例)。
- 图签栏(标题块)固定在右下:图号 `DWG-01/27`、比例 `1:1`、修订 `REV A`、日期——每页必填,这是签名元素。

## 图形母题(白名单)

1. **图框**:每页 1.5px 白线内框,四边留出 64px;框外左上角落图号。
2. **网格**:背景 96px 方格,1px --line-dim、透明度 18%;主网格每 4 格加粗一次。
3. **尺寸标注**:带端点箭头的引伸线 + 数字,用来"丈量"页面上的数据——条形图的长度、数值的落差,都必须用标注线标出,这是本方案的核心语法。
4. **虚线与剖面线**:虚线表"隐藏/推断",45° 剖面线填充表"截断面",语义固定不得挪用。

禁止:实色块面(除面板底)、圆角、阴影、渐变、任何手绘风元素。

## 动效

- **签名动效·绘制**:所有线条与图形以"绘制"方式进场——`stroke-dashoffset` 从全虚到实,速度恒定(机械笔速,约 800px/s),像笔走过去。文字在所属线条画完后 100ms 内出现,不做自己的动画。
- **标注弹定**:尺寸标注线先画出引线,数字以 steps(2) 跳到位,像盖章。
- **翻页·换图**:整页向下平移出画、新页从上平移入画(换图纸动作),400ms,线性;换图瞬间图签栏先翻牌更新图号。
- **圈注**:洋红圈注用椭圆路径绘制 600ms,手绘感禁止(必须匀速)。
- 数据条:不做生长,做成"排线填充"——剖面线从左到右逐根画出。
- 循环动画:仅允许网格 20s 周期 1% 透明度呼吸,其余静止。

### 结束页与退场 · 归档入柜

- 结束页 = 一张"竣工图":中央大号图签栏,结论一句话 + 全片数据清单(等宽小字),无图表。
- 退场:洋红"竣工"章以 steps(2) 跳盖在图签栏上(带 1 次 60ms 顿感)→ 全图线条按进场的**逆序**从右向左擦除(绘制的逆运算,800px/s)→ 只剩图框与图签 → 整张图纸向下平移出画(收入图柜,400ms 线性)→ 网格独留 600ms → 蓝底定格 ≥ 1s。
- 干净帧:图纸蓝底 + 网格,无文字。

## 数据可视化

- 一切图表转译为制图语言:柱状图 = 带剖面线填充的矩形 + 顶部长度标注;对比 = 两矩形间画落差引伸线标 Δ 值;时间 = 水平尺度尺。
- 数字必须出现在标注线上,不允许只画不标。

## 适配

架构解析、流程推演、benchmark 方法学、任何"带你拆解"的内容。不适合情绪化叙事。

# 02 · 瑞士网格 Swiss Grid

## 立意

国际主义平面风格:**内容即秩序**。严格的数学栅格、无装饰的黑体、唯一的信号红。它的力量来自克制——当一切都是白底黑字,那一点红就是全部的情绪。

与构成主义的区别:构成主义是革命的呐喊(斜线、拼贴、水印大字),瑞士网格是**编辑部的事后总结**(正交、编号、脚注)。一个动,一个静。

## 色板

```css
:root{
  --paper: #FAFAF7;  /* 纸白:微暖,非纯白 */
  --ink:   #111111;  /* 文字黑 */
  --gray:  #8A8A85;  /* 次级灰 */
  --hair:  #D8D8D2;  /* 毛发线 */
  --red:   #E4032E;  /* 瑞士红:全页唯一彩色 */
}
```

约束:红每屏 ≤ 2 处,面积 ≤ 1%;只允许红、黑、灰三阶,任何第二彩色禁止(多场对比用灰度阶梯:100%/70%/45%/25% 黑);红色语义固定为"当前/结论/否定"三选一,页内不得混用。

## 字体与排版

- 西文:Helvetica Now / Neue Haas Grotesk(备选 Inter),标题 700,正文 400。
- 中文:Noto Sans SC,字重同上。
- **栅格即设计**:12 列栅格,列距 32px;所有元素必须咬合格线,任何"凭感觉挪 10px"禁止。
- 标题可跨栏放大至 120–160px,允许出血到页缘;正文固定 4 栏宽。
- 每页必须有页码与章节编号,格式 `3.2` / `07/16`,挂栅格固定位,等宽数字。

## 图形母题(白名单)

1. **毛发线**:0.75px --hair 分隔线,正交,绝不倾斜。
2. **编号圆**:红底白字小圆(直径 48px),表步骤/章节序号——全方案唯一允许的非矩形态。
3. **脚注区**:页面底部 1/6 为脚注带,毛发线隔开,放来源与注释。

禁止:斜线、斜体、投影、圆角卡片、图标装饰、图片描边。

## 动效

- **签名动效·排版落版**:文字按栅格块逐个"落版"——从上方 24px 落下 + 透明度 0→1,300ms,`cubic-bezier(0.2,0,0,1)`(急停),像铅字压进纸里。
- **红移**:强调转移时,旧红元素褪色为黑、新元素由黑变红,交叉 240ms——全片只有这一种"强调动画"。
- **翻页·推格**:沿栅格方向水平推页(右出左入),360ms,无缓动花哨,线性。
- 数据条:从栅格左缘以步进式(每 80ms 一跳,共 5 跳)跳到终值——量化感,不连续。
- 循环动画:全禁。瑞士网格不允许任何东西无端动。

### 结束页与退场 · 版权页停格

- 结束页 = colophon:制作信息、数据来源、字体与工具 credits,按栅格排成一页编辑部版权页,页码 `16/16` 照常落位——克制到底,不煽情。
- 退场:全片最后一处红褪色为黑(240ms,"红移"的最后一次执行)→ 整页沿栅格向下推格出画(360ms 线性)→ 纸白空页停 1.5s。
- 干净帧:纸白 + 页码。不允许任何谢幕文字。

## 数据可视化

- 图表 = 黑灰阶梯矩形的精确排列,红色只标当前/结论项。
- 表格是主战场:毛发线表格 + 等宽数字右对齐,对比用字重(700)而非颜色。
- 大数字允许 200px+ 跨栏黑字,红只给单位或脚注编号。

## 适配

观点输出、对比论证、"用数据讲道理"的长文拆解;最不适合游戏/娱乐向内容。

# 03 · 磷光终端 Phosphor

## 立意

1980 年代的琥珀单色监视器:**一切都是字符,一切都在示波**。炭黑底、琥珀磷光字、扫描线、辉光余韵。它不是"复古皮肤",而是一套完整的限制:只能用终端字符表达一切——这限制本身就是风格。

与远岸的区别:远岸是 2020s 的冷静纪念碑,磷光是 1985 的嗡鸣机柜。远岸静止,磷光**永远在轻微地活**(闪烁、游标、扫描)。

## 色板

```css
:root{
  --tube:    #0A0806;  /* 显像管黑:极轻暖相 */
  --phos:    #FFB000;  /* 琥珀磷光:主色,一切文字与图形 */
  --phos-hi: #FFD25F;  /* 高亮磷光:当前行、结论值 */
  --phos-lo: #7A5200;  /* 衰减低磷:注释、坐标轴、已读内容 */
  --alert:   #FF3C1E;  /* 告警红橙:仅错误/负值,每屏 ≤ 2 处 */
}
```

约束:单色纪律——除 alert 外无第二色相;所有元素带 `0 0 8px currentColor` 级微辉光(显像管物理,全方案唯一允许的发光);扫描线叠加层:1px 黑线每 3px 一条、透明度 8%,固定不平移。

## 字体与排版

- 唯一字体:IBM Plex Mono / VT323,全等宽。中文用等宽黑体对齐字符格。
- 一切对齐**字符格**(ch 单位),栅格即字符格:行高 1.5,元素间距以整行计。
- 每页顶部一行状态栏:`REC ● 00:04:12 ▮ TTY1 80×25` 风格,等宽,--phos-lo。
- 游标 `▮` 常驻于当前行尾,530ms 闪烁——签名元素。

## 图形母题(白名单,全部字符绘制)

1. **ASCII/Unicode 线框**:`┌─┐│└─┘` 绘面板,`═` 双线表标题栏。
2. **字符条形图**:`████████░░` 与 `▁▃▅▇` 火花线。
3. **示波轨迹**:关键数值旁附一条正弦/方波 SVG 轨迹,1px,--phos-lo,作为"信号"隐喻。
4. **辉光晕影**:四角轻微暗角(8% 黑径向),显像管曲率暗示。

禁止:位图图片、彩色、圆角 >2px、无衬线黑体标题。

## 动效

- **签名动效·打字机**:正文逐字符打出,30–60 字/秒,行间停顿 80ms;关键数字打出后整行亮一档(--phos → --phos-hi)。
- **磷光余辉**:强调元素亮起到 --phos-hi 后以 1.2s 指数衰减回落,像磷光余韵——本方案唯一的发光动效。
- **翻页·清屏重载**:`CLEAR` → 黑屏 80ms → 新页从头打字。段落级换页可加一次全屏扫描线滚动 200ms(垂直回扫)。
- **数据图·逐列点亮**:字符条逐列从 `░` 到 `█`,每列 40ms,像采样。
- 循环允许(终端是活的):游标闪烁、状态栏走时、示波轨迹 8s 周期缓移,其余静止。

### 结束页与退场 · CRT 关机

- 结束页 =  logout 画面:状态栏走时停止,逐行打出 `LOGOUT`、`SESSION TERMINATED`、总运行时长三行,游标留在行尾。
- 退场:游标闪 3 次 → 画面垂直收缩成一条水平亮线(200ms)→ 亮线缩成一个亮点(150ms)→ 亮点以磷光余辉指数衰减 1.2s 至全黑。显像管物理的完整关机,全片辉光在此得到唯一一次主角待遇。
- 干净帧:全黑。

## 数据可视化

- 一切图表字符化:排行 = 字符条 + 数值右对齐;趋势 = 火花线;对比 = 双行 diff 式 `-`/`+` 前缀。
- 负值加 alert 色并以 `!` 前缀;表格用线框字符,禁止灰底。

## 适配

终端实录、代码/日志叙事、"让模型跑给你看"的过程流;不适合大图表与多栏对比。

# 04 · 浮世绘现代 Ukiyo Modern

## 立意

和纸底、木版套色、骨线勾勒:**把内容画成一幅现代浮世绘**。平涂色块、粗骨线、留白即余韵。它的动效哲学是"版画动起来"——波纹扩散、云气横流,全部限定在平涂色块的物理里,绝不立体、绝不透视。

情绪定位:全部方案里唯一"暖"的一套,适合讲故事。

## 色板

```css
:root{
  --washi:  #F2EAD8;  /* 和纸:暖米,带极轻纤维纹理(噪声 3%) */
  --indigo: #1B3A5C;  /* 靛蓝:主骨线与大色块 */
  --shu:    #C73E2C;  /* 朱红:点题色,落款/关键值 */
  --sumi:   #2B2B28;  /* 墨:正文 */
  --gold:   #B98A2F;  /* 金泥:次级强调,仅线与小面 */
  --mist:   #8FA3B0;  /* 霞灰:次要层 */
}
```

约束:套色纪律——每屏色相 ≤ 3(靛蓝、朱红、金泥三选二 + 墨);平涂无渐变;色块必须由 3–5px 靛蓝或墨骨线收边(木版套印感);朱红每屏 ≤ 2 处,语义固定为"落款/结论"。

## 字体与排版

- 标题:Noto Serif SC 900,允许竖排(签名排版);横排时字距 +0.05em。
- 正文:Noto Serif SC 400,行高 1.9,比我们其他所有方案都松。
- 落款:每页右下一枚 48px 正方形朱红"印",内刻页码篆意数字(白文),全片统一位置——签名元素。
- 数字可用 tabular 衬线(Old-style figures 禁止,录屏需等高)。

## 图形母题(白名单)

1. **骨线波**:平涂靛蓝 + 白骨线的层叠波,3–5 层,表"历程/量级"。
2. **云气纹**:转角云纹带,横向贯穿,表章节分隔。
3. **円相**:墨或金泥一笔圆(允许书法飞白),表"阶段完成"。
4. **霞带**:--mist 平涂宽带斜托内容,全方案唯一允许的斜元素。

禁止:透视、阴影、立体、照片写实、西洋几何装饰(直格纹、checker)。

## 动效

- **签名动效·套印**:每页元素按"版次"进场——先骨线(300ms 描画),再色块(从骨线框内擦入 400ms),最后文字淡落 200ms;三版之间停顿 150ms,像等墨干。
- **波式强调**:关键值出现时,身后展开 2 圈骨线波纹(平涂圆环扩散 + 淡出,800ms 封顶)。
- **翻页·横卷**:整页横向卷动(右入左出),500ms,`cubic-bezier(0.3,0,0.2,1)`,页缘露出 8px 和纸卷边。
- **云过**:章节切换时云气纹带横向流过全屏 600ms,承上启下。
- 循环允许:骨线波 10s 周期 ±4px 横移(浮世绘的海永远在动),其余静止。

### 结束页与退场 · 收卷落款

- 结束页 = 一幅"完"字小品:中央円相一枚,内书"完"(墨),右下落款处钤全片最大一枚朱红印(96px,白文)。
- 退场:印章从 1.15 倍缩至 1.0 落定(带 80ms 顿感,如钤印)→ 云气纹带横过全屏(600ms)→ 整页从右向左**收卷**成画轴(500ms,横卷的逆运算)→ 画轴缩小居中 → 整体明度缓沉至墨黑(1.2s)→ 留印位一点朱红 800ms 后熄。
- 干净帧:全黑,或和纸底 + 朱红印一枚(二选一,定稿时锁定)。

## 数据可视化

- 图表转译为版画语汇:对比 = 波高;排行 = 山形序列(等高平涂山脊,本机座染朱红);时间 = 云纹带刻度。
- 数值以竖排小字标注在图形旁,朱红只标结论值。
- 禁止坐标轴与网格——浮世绘没有直角坐标系,量级靠形的大小与落款数字。

## 适配

历程叙事、复盘故事、"一个本地小模型的参赛记"这类有人文温度的文本;不适合密集数据页。

# 05 · 合成波 Synthwave

## 立意

落日、铬字、地平网格:**1980s 想象的未来**。这是全部方案里唯一允许"张扬"的一套——渐变、辉光、铬面全解禁,因为它们是风格本体。节奏快、能量高,为 BGM 驱动的蒙太奇而生。

与 P3R 的区别:P3R 是日式游戏 UI(静帧海报式构图),合成波是 MV(一切都在向地平线运动)。

## 色板

```css
:root{
  --dusk:   #0D0418;  /* 暮空黑紫 */
  --sky:    linear-gradient(#0D0418, #2B0F4C 55%, #FF2E88 100%); /* 落日天:全方案唯一大渐变 */
  --chrome: #E8F4FF;  /* 铬白:标题 */
  --pink:   #FF2E88;  /* 品红霓虹 */
  --cyan:   #2EE6FF;  /* 青霓虹 */
  --sun:    #FFB02E;  /* 落日橙:仅落日本体 */
  --grid:   #FF2E88;  /* 地平网格同品红,透明度 40% */
}
```

约束:霓虹双色(品红/青)必须成对出现、分工固定——品红=过去/基准/他者,青=当前/本机/结论;辉光只属于霓虹元素,铬字不带辉光;落日橙只属于太阳,禁止挪用。

## 字体与排版

- 标题:镀铬斜体感——Outfit/Orbitron 800 + `italic` + 6° 斜置,铬面纵向渐变(白→浅蓝→白),描 1px 暮紫边。
- 数字:Orbitron tabular;正文:Noto Sans SC 400。
- 构图对称轴心:落日永远在地平线正中,内容左右两列挂两侧,底部留 1/3 给网格地。

## 图形母题(白名单)

1. **条纹落日**:正圆落日被 4–6 条水平缝切割,悬于地平线。
2. **透视地平网格**:品红网格向消失点收束,动画中向观众流动。
3. **铬框**:内容面板用 1px 铬渐变边框 + 2px 圆角(全方案唯一圆角)。
4. **星**:暮空散布 1–2px 星点。

禁止:平面直角网格(透视才合法)、衬线、纸纹理、第三霓虹色。

## 动效

- **签名动效·驶向地平线**:地平网格以 400px/s 向观众流动(透视平移循环),所有进场元素沿透视方向由小放大冲入(从地平线 30% 缩放到 100%,500ms,`cubic-bezier(0.1,0.8,0.3,1)`)。
- **霓虹点亮**:标题与关键值以"点亮"进场——从暮紫描边到霓虹全亮 300ms,带 1 次 100ms 电压不稳闪烁。
- **翻页·换轨**:整页沿透视轴推远消失 + 新页从地平线冲来,450ms;段落切换加落日一次"落半格再升起"。
- **数据条·光轨**:条形以青/品红光轨拖尾画出,头部辉光,600ms。
- 循环允许(本方案默许常动):网格流动、星点闪烁(3 颗,错峰 4s)、落日微浮 ±6px/8s。

### 结束页与退场 · 日落收光

- 结束页 = 驶向落日:无面板无数据,铬字一句话悬在落日上方,网格常流。
- 退场:网格流速 ×3(镜头加速)→ 落日向地平线以下沉降,天空随之一路压暗(粉→紫→暮黑,1s)→ 铬字与霓虹以"电压不稳"闪烁 2 次后熄灭 → 网格流减速至静止 → 全黑前留一条品红地平线 1s → 地平线渐隐 400ms。
- 干净帧:全黑。BGM 尾奏应卡在落日没线的一帧,剪辑点写进分镜。

## 数据可视化

- 一切图表立在地平线上:柱 = 透视光柱(向天生长),对比 = 双霓虹,时间轴 = 网格道数。
- 数值用铬白等宽挂光柱顶;本机/结论恒为青,对照恒为品红,全片不换。

## 适配

快节奏混剪、成绩高光集锦、配 BGM 的"战报"视频;不适合长文细读页(每页信息 ≤ 3 个数据点)。

# 06 · 白盒画廊 White Cube

## 立意

美术馆白盒空间:**内容是被策展的展品**。展墙白、极多留白、展签式排版、博物馆级的字体排印。动效是"导览"——缓慢、笃定、像镜头在展厅里推移。全部方案中节奏最慢、最适合长文的一套。

与瑞士网格的区别:瑞士是编辑部(密、编号、效率),白盒是美术馆(疏、凝视、余白)。瑞士用红点睛,白盒用**空白**点睛。

## 色板

```css
:root{
  --wall:  #F5F4F0;  /* 展墙白:中性微暖 */
  --ink:   #1A1A18;  /* 墨黑:正文 */
  --cap:   #6B6B66;  /* 展签灰:注释、图注 */
  --plinth:#E3E1DA;  /* 展台灰:面板与分隔 */
  --solo:  #1F4D8F;  /* 点题藏青:全片唯一彩色,仅结论数字与一条展线 */
}
```

约束:藏青每屏 ≤ 1 处(一件"展品");色阶只有 wall/plinth/cap/ink 四阶灰 + 一色;任何高饱和彩色、渐变、纹理禁止;留白率(无任何元素的面积)≥ 55%,写进验收。

## 字体与排版

- 标题:Noto Serif SC 600,字距 +0.08em,60–84px——展厅标题从不喊。
- 正文:Noto Sans SC 400,34px,行高 1.9,栏宽 ≤ 30 字。
- 展签格式固定:序号(等宽小字)/ 题目(衬线)/ 三行以内说明(灰)/ 数据(等宽 tabular)。位置:内容区左下,像挂在展品旁。
- 数字:等宽 tabular,结论数字藏青,其余墨黑。

## 图形母题(白名单)

1. **展线**:1px 墨线,水平,长度 = 栏宽,悬挂标题或分隔展区。
2. **展台**:--plinth 平涂矩形,托起图表这件"展品",无框无影。
3. **钉距刻度**:展签左侧 4 枚 2px 方点纵向排列,表展签序号。
4. 除此之外什么都不需要——空墙就是母题。

禁止:图标、描边卡片、checker、斜元素、任何"活泼"的东西。

## 动效

- **签名动效·导览推移**:翻页 = 镜头横移——旧页以 120px 视差(背景慢、内容快)向左退场,新页从右入,600ms,`cubic-bezier(0.25,0,0,1)`,像走过一面展墙。
- **展品亮灯**:关键数据/图表进场时,展台区域亮度 +4% 渐起 800ms(允许超 500ms,此为本方案特批的"慢"),其余元素淡入 400ms。
- **展签翻牌**:展签文字三行依次 90ms 间隔淡入,无位移。
- **数字·静默呈现**:不滚动不跳动,直接以藏青呈现——白盒里数字不需要表演。
- 循环动画:全禁。美术馆里只有观众在动。

### 结束页与退场 · 闭馆空墙

- 结束页 = 最后一面展墙:一枚展台、一句结语、一枚展签,留白率 ≥ 70%。
- 退场:展台"亮灯"逆运算——亮度缓回 800ms → 展签三行按进场逆序淡出 → 展线从右向左擦除 400ms → 镜头最后一次横移,停在一面**空墙**上凝视 2s(签名收尾)→ 整墙明度缓降至全黑(1.5s,全方案最慢动画,特批)→ 全片最后一点藏青在熄灯前褪成墨黑。
- 干净帧:全黑。空墙凝视的 2s 不许剪辑压缩。

## 数据可视化

- 图表极简:细线(1.5px 墨)+ 等宽标注,柱条用 --plinth 填充、墨描边,结论项藏青。
- 一图一数:每个展台只讲一个数,图表注释 ≤ 2 行。
- 时间/流程用"展墙序列":等距展台一字排开,无箭头(参观顺序即方向)。

## 适配

深度分析、方法学复盘、需要逐句读完的长文;最不适合快节奏赛事集锦。
